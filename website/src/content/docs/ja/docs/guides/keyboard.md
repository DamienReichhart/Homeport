Homeport はキーボードで操作できます。<kbd>Mod</kbd> <kbd>K</kbd> を押すと[コマンドパレット](#コマンドパレット)が開き、どのページでも <kbd>?</kbd> を押すと、そこで使えるすべてのショートカットが表示されます。

以下の **Mod** は、macOS では <kbd>⌘</kbd>、Windows と Linux では <kbd>Ctrl</kbd> を意味します。macOS では <kbd>Alt</kbd> は <kbd>⌥</kbd> です。

## コマンドパレット

<kbd>Mod</kbd> <kbd>K</kbd> で、どのページからでもコマンドパレットが開きます。目的のものを入力し、<kbd>↑</kbd> と <kbd>↓</kbd> で移動して <kbd>Enter</kbd> を押します。<kbd>Esc</kbd> でパレットが閉じ、元の場所に戻ります。一覧には次のものが表示されます:

- **移動** — サイドバーのすべてのページ。`vol` と入力して <kbd>Enter</kbd> を押すと、ボリュームが開きます。
- **ホスト** — すべてのホストとその状態。ホスト名の一部を入力すると、そのホストに切り替えられます。
- **操作** — **コンテナを実行**、**イメージをプル**、**新しいスタック**、**選択したホストの未使用データを削除**、**ホストを追加**、**ホストを管理**、**アップデートを確認**、**キーボードショートカットを表示**。
- **設定** — **テーマ: ライト**、**テーマ: ダーク**、**テーマ: システムに合わせる**。

ホストが必要な操作（コンテナの実行、プル、新しいスタック、未使用データの削除）は、選択したホストが接続している間だけ表示されます。

### すべてのホストを検索する

2 文字以上入力すると、パレットは接続しているすべてのホストの **コンテナ**、**スタック**、**イメージ**、**ボリューム**、**ネットワーク** も検索します。ホストを切り替えずに「`postgres` はどこで動いているか」がわかります。名前、短い ID、そしてコンテナの場合はそのイメージとスタックに一致します。入力した文字で始まる名前が先に表示されます。

- 結果は種類ごとにまとめられ、**N 件をすべて表示** を選ぶまでは種類ごとに 5 件まで表示されます。各結果にはホストが表示され、コンテナとスタックについては実行中かどうかも表示されます（例: _prod-server · 実行中_）。
- 結果を選ぶと、そのホストに切り替わって対象が開きます。コンテナやスタックの場合はそのページ、イメージ、ボリューム、ネットワークの場合は、それで検索した状態のイメージ、ボリューム、ネットワークのページです。
- 接続していないホストはスキップされ、パレットにその数が表示されます（例: _2 台のホストは検索されていません（未接続）_）。

Homeport は 2 文字入力されてから初めて一覧を読み込み、その後は各ホストのリアルタイムのイベントで最新の状態に保ちます。ログ、ファイル、compose 定義は検索されません。ショートカットがある項目には、そのショートカットが表示されます。何も入力していないときは、最後に使った項目が **最近使用した項目** の下に先頭に表示されます。これは Homeport を終了するまで保持されます。

## ショートカット

### どこでも

| キー                                       | 動作                                                                                    |
| ------------------------------------------ | --------------------------------------------------------------------------------------- |
| <kbd>?</kbd>                               | キーボードショートカットを表示する                                                      |
| <kbd>Mod</kbd> <kbd>1</kbd> … <kbd>9</kbd> | サイドバーのページを順に開く: 概要、コンテナ、イメージ…                                 |
| <kbd>Mod</kbd> <kbd>,</kbd>                | 設定を開く                                                                              |
| <kbd>Alt</kbd> <kbd>↑</kbd> / <kbd>↓</kbd> | ホストページの並び順で、前または次のホストを選択する                                    |
| <kbd>Mod</kbd> <kbd>R</kbd>                | 選択したホストの一覧を更新する: コンテナ、イメージ、ボリューム、ネットワーク、スタック… |

サイドバーのページにポインターを合わせると、そのキーが表示されます。

### ページ内

| キー         | 動作                                                                                                                                         |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| <kbd>/</kbd> | ページの検索欄にフォーカスする。空の欄で <kbd>Esc</kbd> を押すと、欄から離れます。                                                           |
| <kbd>N</kbd> | ページの主な操作を開始する: **コンテナを実行**、**プル**、**ボリュームを作成**、**ネットワークを作成**、**新しいスタック**、**ホストを追加** |

ページの主な操作のボタンにポインターを合わせると、<kbd>N</kbd> が表示されます。

### 入力中

1 つのキーだけのショートカット（<kbd>N</kbd>、<kbd>/</kbd>、<kbd>?</kbd>、<kbd>Alt</kbd> と矢印キー）は、入力欄、スタックのエディター、ダイアログで入力している間は動作せず、その文字が入力されます。<kbd>Mod</kbd> を使うショートカットは、そこでも動作します。コンテナの **ターミナル** では、すべてのキーがコンテナに送られ、ショートカットは動作しません。
