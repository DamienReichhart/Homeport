title: ログとターミナル

Pod のページには **ログ** と **ターミナル** のタブがあり、ワークロードのページにはそのすべての Pod を対象にした **ログ** タブがあります。日常的に使う `kubectl logs` と `kubectl exec -it` を、クラスター自身の認証情報で Kubernetes API を通じて行えます。

## ログ

**ログ** は、コンテナのログを書き込まれたそばからストリーミングします。ホスト上のコンテナと同じビューアーです:

- **履歴**: 最後の 100 行、1,000 行、10,000 行、またはすべての行から始めます。
- **期間**: 直近の数分、数時間、数日の行だけを表示します。
- **タイムスタンプ**: Kubernetes が各行を記録した時刻です。
- **追従**: 最新の行を表示し続けます。オフにすると、新しい行が届き続ける間もさかのぼって読めます。
- **検索**、**クリア**、**ダウンロード**（それまでに表示された行をテキストファイルとして）。

複数のコンテナを持つ Pod には **コンテナ** の選択欄があり、init コンテナには印が付きます。最初は `kubectl` が選ぶのと同じコンテナが開きます。Pod の `kubectl.kubernetes.io/default-container` アノテーションで指定されたコンテナ、なければ最初のアプリコンテナです。

Kubernetes はコンテナの標準出力と標準エラーをまとめて保持するため、ホストのコンテナにあるような stdout/stderr の絞り込みはありません。

ストリームはタブを離れると止まり、コンテナが停止するとその旨が表示されます。

### クラッシュした理由を調べる

コンテナが再起動した場合、**前回のインスタンス** で最後の再起動の前の実行のログを表示できます。`CrashLoopBackOff` の Pod なら、クラッシュした実行のログです。`kubectl logs --previous` と同じです。一度も再起動していないコンテナでは、表示するものがないためオフになっています。

コンテナがまだ起動していない場合（`ContainerCreating`、または再起動を待っている間の `CrashLoopBackOff`）、ログの位置にその旨が理由とともに表示されます。待機している理由は Pod のページに表示されます。

### ワークロードのログ

Deployment、StatefulSet、DaemonSet、Job の **ログ** タブは、すべての Pod のログを書き込まれたそばから交互に表示します。`kubectl logs -l app=api --prefix` のように、各行には Pod ごとの色でその Pod のラベルが付きます。1 つの Pod だけを読むにはその Pod を選び、テンプレートに複数のコンテナがある場合はコンテナも選びます。

## ターミナル

**ターミナル** は、Pod の動作中のコンテナの 1 つでシェルを開きます。イメージにあれば `bash`、なければ `sh` です。代わりに入力欄にコマンドを入力すると（`psql -U app shop`、`top`）、**接続** で、シェルと同じようにクォートして実行します。

本物の TTY なので、`vi`、`top`、色、矢印キーが使え、ウィンドウのサイズを変えるとコンテナ内のターミナルのサイズも変わります。プロセスが終了すると、ターミナルに終了コードが表示されます。**再接続** で別のプロセスを開始します。タブを離れると、コンテナ内のプロセスは終了します。

### 開けない場合

- **シェルがない**: 最小限の（distroless の）イメージにはシェルがまったくありません。イメージにあるコマンドを入力するか、ターミナルから `kubectl debug -it <pod> --image=busybox --target=<container>` でデバッグコンテナをアタッチしてください。Homeport はデバッグコンテナを作成しません。
- **実行されていない**: 待機中または終了したコンテナでは何も実行できません。完了した Job の Pod は完全に停止しています。
- **許可されていない**: ターミナルを開くには `pods/exec` に対する `create`、ログを読むには `pods/log` に対する `get` が必要で、読み取り専用のロールにはないことがよくあります。Homeport はどちらが必要かを、確認用の `kubectl auth can-i` コマンドとともに示します。

Homeport は Pod との間でファイルをコピーしません（`kubectl cp`）。
