## Node

**Node** には、クラスターが Pod を実行するマシンが一覧表示されます。それぞれ **準備完了** かどうか（cordon されている場合は **スケジューリング無効**）、ロール、kubelet のバージョン、内部 IP、プラットフォーム、割り当て可能な CPU とメモリが表示されます。

/>

CPU はコア数で（`3920m` は `3.92`）、メモリは GB で表示されます。Kubernetes が報告するのは Pod に **割り当て可能** な量で、kubelet とシステムが一部を確保するため、マシンの実際の量より少し少なくなります。 クラスターで metrics-server が動いていれば、**CPU 使用量** と **メモリ使用量** に、各 Node がそのうちどれだけ使っているかが表示されます（[CPU とメモリ](/docs/clusters/metrics/)）。

Node のページには、OS イメージ、カーネル、コンテナランタイム、アドレス、taint、ラベル、そして容量と Pod に割り当て可能な量が並べて表示されます。続いて、すべての Namespace でその Node 上で動作している **Pod**、**状態**（メモリ、ディスク、PID の逼迫）、**イベント**、**YAML** があります。Pod のページからは、その Node にリンクしています。 metrics-server があれば、**メトリクス** にその CPU とメモリが、割り当て可能量に対するグラフで表示されます（[CPU とメモリ](/docs/clusters/metrics/)）。

## イベント

<DocScreenshot
  name="cluster-events"
  alt="「イベント」ページ: 先頭に 3 つの警告（バックオフ中の Pod、プルできないイメージ、準備完了でない Node）、続いて通常のイベント。それぞれオブジェクト、メッセージ、回数、経過時間とともに表示されている。"
/>

**イベント** には、選択した Namespace（またはすべての Namespace）で Kubernetes が報告したことが一覧表示されます。警告が先頭で、その後は新しい順です。それぞれ、理由、対象のオブジェクト（そのオブジェクトのページへのリンク付き）、メッセージ、発生回数、最後に発生した時刻が表示されます。**警告** または **通常** で絞り込み、理由、オブジェクト、メッセージで検索できます。一覧はリアルタイムで更新されます。

Kubernetes はイベントを約 1 時間保持するので、静かなクラスターでは一覧が空でも正常です。どのオブジェクトのページにも、それぞれの **イベント** タブがあります。

## 認証情報で見られないものがある場合

Node は Namespace に属さないため、一覧表示にはクラスター全体の権限が必要で、多くのユーザーはそれを持っていません。その場合、ページには「この認証情報では nodes に対する「list」は許可されていません。」と表示され、ほかのページはすべて引き続き動作します。
