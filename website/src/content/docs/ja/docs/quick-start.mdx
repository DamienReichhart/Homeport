このガイドでは、インストール直後の状態から、最初のホストでコンテナを実行するまでを説明します。

## 1. ホストを追加する

Homeport を初めて開くと、**Homeport へようこそ** が表示されます。

このマシンで Docker Engine が動作していれば、**このマシンで見つかったもの** にバージョンとともに表示されます（例: `Docker Desktop · Engine 27.3.1`）。その横の **追加** を選べば接続は完了です。[ステップ 2](#2-look-around) に進んでください。

代わりにリモートのエンジンに接続するには、**別のホストを追加** を選びます:

<Steps>

1. 接続方法を **SSH**、**TLS**、**TCP**、**ローカルソケット** から選びます。サーバーには通常 SSH を選びます。

2. ホストに、見てわかる **名前** を付けます（例: `production`）。

3. 接続の詳細を入力します。SSH の場合は **サーバー**、**ポート**、**ユーザー** と、Docker が標準の場所にない場合は **リモートソケットのパス** です。

4. **ホストを追加** を選びます。Homeport がホストのページを開き、接続を開始します。

</Steps>

<DocScreenshot
  name="add-host-ssh"
  alt="SSH が選択された「ホストを追加」ページ。"
  caption="SSH のホストを追加しているところ。Homeport はこのホスト専用のキーを作成します。"
/>

SSH のホストは、初回にさらに 2 つの作業が必要です。手順は [SSH のホスト](/docs/hosts/ssh/)で説明しています:

- **サーバーのキーを信頼する。** Homeport がサーバーのフィンガープリントを表示します。照合して **このキーを信頼** を選びます。
- **Homeport のキーを許可する。** **サーバーで Homeport を許可** の下にあるコマンドをコピーしてサーバーで実行し、**再接続** を選びます。

ステータスが **接続済み** になれば完了です。

## 2. 画面を見てみる

サイドバーにはリソースの種類ごとにページがあり、どのページもサイドバー上部の **ホストの切り替えメニュー** で選んだホストの内容を表示します:

| ページ           | 表示される内容                                                         |
| ---------------- | ---------------------------------------------------------------------- |
| **概要**         | ホストごとのカード、選択したホストのエンジン、ディスク使用量、イベント |
| **コンテナ**     | スタックごとにまとめたすべてのコンテナと、リアルタイムの CPU とメモリ  |
| **イメージ**     | ローカルのイメージ、それを使っているもの、プルと未使用の削除           |
| **ボリューム**   | ボリュームと、それを使っているコンテナ                                 |
| **ネットワーク** | ネットワーク、そのサブネット、接続されているコンテナ                   |
| **スタック**     | Compose プロジェクト（管理スタックと外部スタック）                     |
| **イベント**     | Homeport の接続以降にエンジンが報告したこと                            |
| **設定**         | テーマ、このマシンが対応していること、ライセンス                       |

Homeport はエンジンが変更を報告するたびに更新されるので、更新ボタンは必要ありません。ターミナルでコンテナを起動すれば、すぐに表示されます。

## 3. コンテナを実行する

<Steps>

1. **コンテナ** を開き、**コンテナを実行** を選びます。

2. **イメージ** に `nginx:alpine` などを入力します。ホストにそのイメージがなければ、Homeport が先にプルします。

3. **ポート** で **ポートを追加** を選び、ホストのポート `8080` をコンテナのポート `80` に割り当てます。

4. **実行** を選びます。Homeport が新しいコンテナを **ログ** タブで開きます。

</Steps>

「コンテナ」ページに戻ると、ポート `8080:80/tcp` がリンクになっています。選択すると、ブラウザーでサイトが開きます。

## 4. ホストをさらに追加する

ホストの切り替えメニューの **ホストを追加…** で、ホストをいくつでも追加できます。「概要」にはすべてのホストがまとめて表示され、カードを選ぶとそのホストに切り替わります。

<Aside type="tip">
  Homeport は選択していたホストを記憶し、起動時にすべてのホストに再接続します。
</Aside>
