**Homeport** は、このマシンの Docker Engine も、SSH、TLS、TCP でつなぐリモートの Docker Engine も、どこにあっても管理できるデスクトップアプリです。kubeconfig から到達できる Kubernetes クラスターも扱えます。Docker Desktop と同じ発想で作られています。Windows、macOS、Linux で動作し、無料で、[GNU Affero General Public License バージョン 3](https://github.com/DamienReichhart/Homeport/blob/main/LICENSE) のもとで公開されたオープンソースです。

Homeport 自体はコンテナを実行しません。すでにお使いの Docker Engine（**ホスト**と呼びます）に接続し、そこにあるコンテナ、イメージ、ボリューム、ネットワーク、Compose の**スタック**をすべて 1 つのウィンドウで扱えるようにします。kubeconfig の Kubernetes **クラスター**にも接続し、そこで動いているものを閲覧できます。

## このドキュメントで使う言葉

Homeport は物事を正確に呼び分けており、このドキュメントもそれに従います。

- **ホスト**は、Homeport が接続する Docker Engine です。すべてのコンテナ、イメージ、ボリューム、ネットワーク、スタックは、ちょうど 1 つのホストに属します。
- **クラスター**は、Homeport が接続する Kubernetes クラスターで、kubeconfig のコンテキストから追加します。
- **スタック**は、ホスト上で動いている Compose プロジェクトです。**管理スタック**は compose ファイルを Homeport が保持しているスタック、**リンクスタック**は compose ファイルをこのコンピューター上のフォルダーに置いているスタック、**外部スタック**はほかの方法でデプロイされたスタックです。外部スタックは**引き継ぐ**ことで管理できます。

すべての用語は[用語集](/docs/reference/glossary/)にあります。
