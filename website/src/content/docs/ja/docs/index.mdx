**Homeport** は、Docker Engine、containerd、Incus を、このマシンのものも、SSH、TLS、TCP でつなぐリモートのものも、どこにあっても管理できるデスクトップアプリです。それらが構成する Swarm、kubeconfig から到達できる Kubernetes クラスター、指定した Nomad クラスターも扱えます。Docker Desktop と同じ発想で作られています。Windows、macOS、Linux で動作し、無料で、[GNU Affero General Public License バージョン 3](https://github.com/DamienReichhart/Homeport/blob/main/LICENSE) のもとで公開されたオープンソースです。

Homeport 自体はコンテナを実行しません。すでにお使いのエンジン（**ホスト**と呼びます）に接続し、そこにあるコンテナ、イメージ、ボリューム、ネットワーク、Compose の**スタック**をすべて 1 つのウィンドウで扱えるようにします。Kubernetes と Nomad の**クラスター**にも接続し、そこで動いているものを確認・管理できます。ホストにもクラスターにも、何もインストールしません。

## このドキュメントで使う言葉

Homeport は物事を正確に呼び分けており、このドキュメントもそれに従います。

- **ホスト**は、Homeport が接続するエンジンです。Docker Engine か、Podman、containerd、Incus などの互換エンジンです。すべてのコンテナ、イメージ、ボリューム、ネットワーク、スタックは、ちょうど 1 つのホストに属します。
- **クラスター**は、kubeconfig のコンテキストから追加する Kubernetes クラスター、またはエージェントの 1 つのアドレスで追加する Nomad クラスターです。
- **Swarm**は Docker Swarm です。所属するホストを通じて見つかり、単独で追加することはありません。
- **スタック**は、ホスト上で動いている Compose プロジェクト、または Swarm 上で動いている Swarm のスタックです。**管理スタック**は compose ファイルを Homeport が保持しているスタック、**リンクスタック**は compose ファイルをこのコンピューター上のフォルダーに置いているスタック、**同期スタック**は git リポジトリに追従するスタック、**外部スタック**はほかの方法でデプロイされたスタックです。外部スタックは**引き継ぐ**ことで管理できます。

すべての用語は[用語集](/docs/reference/glossary/)にあります。
