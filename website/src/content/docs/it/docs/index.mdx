**Homeport** è un’app desktop per gestire Docker Engine ovunque si trovino — quello di questo computer, o Engine remoti tramite SSH, TLS o TCP — e i cluster Kubernetes raggiunti dal tuo kubeconfig, nello spirito di Docker Desktop. Funziona su Windows, macOS e Linux, è gratuita ed è open source sotto la [GNU Affero General Public License, versione 3](https://github.com/DamienReichhart/Homeport/blob/main/LICENSE).

Homeport non esegue container da sé. Si connette ai Docker Engine che hai già, chiamati **host**, e ti offre un’unica finestra per tutto ciò che contengono: container, immagini, volumi, reti e **stack** Compose. Si connette anche ai **cluster** Kubernetes del tuo kubeconfig, per esplorare ciò che vi è in esecuzione.

## Le parole che usiamo

Homeport chiama le cose con precisione, e la documentazione fa lo stesso:

- Un **host** è un Docker Engine a cui Homeport si connette. Ogni container, immagine, volume, rete e stack appartiene esattamente a un host.
- Un **cluster** è un cluster Kubernetes a cui Homeport si connette, aggiunto da un contesto del tuo kubeconfig.
- Uno **stack** è un progetto Compose in esecuzione su un host. Uno **stack gestito** è uno stack il cui file compose è conservato da Homeport; uno **stack collegato** conserva i suoi file compose in una cartella di questo computer; uno **stack esterno** è stato distribuito in un altro modo. Puoi **adottare** uno stack esterno per gestirlo.

Il [glossario](/docs/reference/glossary/) contiene l’elenco completo.
