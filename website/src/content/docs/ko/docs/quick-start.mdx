이 안내서는 Homeport를 막 설치한 상태에서 첫 번째 호스트에 컨테이너를 실행하기까지의 과정을 다룹니다.

## 1. 호스트 추가

Homeport를 처음 열면 **Homeport에 오신 것을 환영합니다**가 표시됩니다.

이 컴퓨터에서 Docker Engine이 실행 중이면 **이 컴퓨터에서 찾음** 아래에 `Docker Desktop · Engine 27.3.1`처럼 버전과 함께 표시됩니다. 옆의 **추가**를 선택하면 연결됩니다. [2단계](#2-둘러보기)로 건너뛰세요.

원격 엔진에 연결하려면 **다른 호스트 추가**를 선택합니다.

<Steps>

1. 연결 방법을 고릅니다. **SSH**, **TLS**, **TCP**, **로컬 소켓** 중 하나입니다. 서버라면 보통 SSH를 선택합니다.

2. 호스트에 `production`처럼 알아보기 쉬운 **이름**을 붙입니다.

3. 연결 정보를 입력합니다. SSH라면 **서버**, **포트**, **사용자**를 입력하고, Docker가 기본 위치에 있지 않으면 **원격 소켓 경로**도 입력합니다.

4. **호스트 추가**를 선택합니다. Homeport가 호스트 페이지를 열고 연결을 시작합니다.

</Steps>

SSH 호스트는 처음 연결할 때 두 가지가 더 필요합니다. [SSH 호스트](/docs/hosts/ssh/)에서 자세히 설명합니다.

- **서버 키를 신뢰합니다.** Homeport가 서버의 지문을 보여 줍니다. 비교한 다음 **이 키 신뢰**를 선택하세요.
- **Homeport의 키를 승인합니다.** **서버에서 Homeport 승인** 아래의 명령을 복사하여 서버에서 실행한 다음 **다시 연결**을 선택하세요.

상태가 **연결됨**으로 바뀌면 완료입니다.

## 2. 둘러보기

사이드바에는 리소스 종류마다 페이지가 하나씩 있으며, 모든 페이지는 사이드바 위쪽의 **호스트 전환기**에서 선택한 호스트를 보여 줍니다.

| 페이지       | 표시 내용                                                       |
| ------------ | --------------------------------------------------------------- |
| **개요**     | 모든 호스트의 카드, 선택한 호스트의 엔진, 디스크 사용량, 이벤트 |
| **보드**     | 연결된 모든 호스트의 컨테이너를 하나의 표로 표시                |
| **컨테이너** | 모든 컨테이너를 스택별로 묶어 실시간 CPU, 메모리와 함께 표시    |
| **이미지**   | 로컬 이미지, 이미지를 사용하는 대상, 이미지 풀과 정리           |
| **볼륨**     | 볼륨과 볼륨을 사용하는 컨테이너                                 |
| **네트워크** | 네트워크, 서브넷, 연결된 컨테이너                               |
| **스택**     | Compose 프로젝트(관리형, 링크된, 동기화, 외부 스택)             |
| **이벤트**   | 엔진이 보고한 내용(30일 동안 보관)                              |
| **설정**     | 테마와 언어, 레지스트리 로그인, 백업, 이 컴퓨터에 있는 것       |

Homeport는 엔진이 변경 사항을 보고할 때마다 새로 고치므로 새로 고침 버튼이 필요 없습니다. 터미널에서 컨테이너를 시작하면 곧바로 나타납니다.

containerd, Incus, Podman 호스트, Swarm, 클러스터는 각각 고유한 페이지를 사이드바에 추가합니다. 사이드바 맨 아래의 **문서**와 **GitHub**는 이 문서와 프로젝트 저장소를 브라우저에서 엽니다.

## 3. 컨테이너 실행

<Steps>

1. **컨테이너**를 열고 **컨테이너 실행**을 선택합니다.

2. `nginx:alpine`처럼 **이미지**를 입력합니다. 호스트에 이미지가 없으면 Homeport가 먼저 풀합니다.

3. **포트**에서 **포트 추가**를 선택하고 호스트 포트 `8080`을 컨테이너 포트 `80`에 매핑합니다.

4. **실행**을 선택합니다. Homeport가 새 컨테이너를 **로그** 탭으로 엽니다.

</Steps>

컨테이너 페이지로 돌아가면 포트 `8080:80/tcp`가 링크로 표시됩니다. 선택하면 브라우저에서 사이트가 열립니다.

## 4. 호스트 더 추가하기

호스트 전환기의 **호스트 추가…** 항목으로 원하는 만큼 호스트를 추가하세요. 개요에서 모든 호스트를 함께 볼 수 있고, 카드를 선택하면 해당 호스트로 전환됩니다.

<Aside type="tip">
  Homeport는 선택했던 호스트를 기억하고, 시작할 때 모든 호스트에 다시 연결합니다.
</Aside>
