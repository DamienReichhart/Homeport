Homeport는 키보드로 사용할 수 있습니다. <kbd>Mod</kbd> <kbd>K</kbd> 키를 누르면 [명령 팔레트](#command-palette)가 열리고, 어느 페이지에서든 <kbd>?</kbd> 키를 누르면 그 페이지에서 쓸 수 있는 모든 단축키를 볼 수 있습니다.

아래에서 **Mod** 키는 macOS에서는 <kbd>⌘</kbd>, Windows와 Linux에서는 <kbd>Ctrl</kbd>을 뜻합니다. macOS에서 <kbd>Alt</kbd>는 <kbd>⌥</kbd>입니다.

## 명령 팔레트

어느 페이지에서든 <kbd>Mod</kbd> <kbd>K</kbd> 키를 누르면 명령 팔레트가 열립니다. 원하는 내용을 입력하고 <kbd>↑</kbd>와 <kbd>↓</kbd>로 이동한 다음 <kbd>Enter</kbd>를 누르세요. <kbd>Esc</kbd>를 누르면 팔레트가 닫히고 원래 있던 곳으로 돌아갑니다. 팔레트에는 다음이 나열됩니다.

- **이동** — 사이드바의 모든 페이지. `vol`을 입력하고 <kbd>Enter</kbd>를 누르면 볼륨 페이지가 열립니다.
- **호스트** — 모든 호스트와 그 상태. 호스트 이름의 일부를 입력하면 해당 호스트로 전환합니다.
- **작업** — **컨테이너 실행**, **이미지 풀**, **새 스택**, **선택한 호스트 정리**, **호스트 추가**, **호스트 관리**, **업데이트 확인**, **키보드 단축키 보기**.
- **설정** — **테마: 라이트**, **테마: 다크**, **테마: 시스템 설정에 맞춤**.

호스트가 필요한 작업(컨테이너 실행, 풀, 새 스택, 정리)은 선택한 호스트가 연결되어 있을 때만 나열됩니다.

### 모든 호스트 검색

두 글자 이상 입력하면 팔레트가 연결된 모든 호스트의 **컨테이너**, **스택**, **이미지**, **볼륨**, **네트워크** 항목도 검색합니다. 호스트를 전환하지 않고도 "`postgres`는 어디에서 실행되나?"라는 질문에 답할 수 있습니다. 이름, 짧은 ID와 일치하는 항목을 찾고, 컨테이너는 이미지와 스택으로도 찾습니다. 입력한 내용으로 시작하는 이름이 먼저 표시됩니다.

- 결과는 종류별로 묶이며, **모두 보기** 항목을 선택하기 전까지는 종류마다 다섯 개씩 표시됩니다. 각 결과에는 호스트가 표시되고, 컨테이너와 스택은 실행 중인지도 표시됩니다. 예: _prod-server · 실행 중_.
- 결과를 선택하면 해당 호스트로 전환하고 결과를 엽니다. 컨테이너나 스택의 페이지, 또는 해당 항목으로 검색한 이미지, 볼륨, 네트워크 페이지가 열립니다.
- 연결되지 않은 호스트는 건너뛰며, 팔레트에 그 수가 표시됩니다. 예: _호스트 2개는 검색하지 않음(연결되지 않음)_.

Homeport는 두 글자를 입력한 뒤에야 목록을 불러오고, 그 뒤로는 각 호스트의 실시간 이벤트로 목록을 최신 상태로 유지합니다. 로그, 파일, compose 정의는 검색하지 않습니다. 각 항목에는 단축키가 있으면 함께 표시됩니다. 아무것도 입력하지 않으면 마지막으로 사용한 항목이 **최근 항목** 아래에 먼저 표시되며, Homeport를 종료할 때까지 유지됩니다.

## 단축키

### 어디서나

| 키                                         | 동작                                                                    |
| ------------------------------------------ | ----------------------------------------------------------------------- |
| <kbd>?</kbd>                               | 키보드 단축키 보기                                                      |
| <kbd>Mod</kbd> <kbd>1</kbd> … <kbd>9</kbd> | 사이드바의 페이지를 순서대로 열기: 개요, 컨테이너, 이미지…              |
| <kbd>Mod</kbd> <kbd>,</kbd>                | 설정 열기                                                               |
| <kbd>Alt</kbd> <kbd>↑</kbd> / <kbd>↓</kbd> | 호스트 페이지에 나열된 순서대로 이전 또는 다음 호스트 선택              |
| <kbd>Mod</kbd> <kbd>R</kbd>                | 선택한 호스트의 목록 새로 고침: 컨테이너, 이미지, 볼륨, 네트워크, 스택… |

사이드바의 페이지 위에 포인터를 올리면 해당 키가 표시됩니다.

### 페이지에서

| 키           | 동작                                                                                                                   |
| ------------ | ---------------------------------------------------------------------------------------------------------------------- |
| <kbd>/</kbd> | 페이지의 검색 필드에 포커스. 빈 필드에서 <kbd>Esc</kbd>를 누르면 필드에서 벗어납니다.                                  |
| <kbd>N</kbd> | 페이지의 주요 작업 시작: **컨테이너 실행**, **풀**, **볼륨 만들기**, **네트워크 만들기**, **새 스택**, **호스트 추가** |

페이지의 주요 작업 버튼에 포인터를 올리면 <kbd>N</kbd>이 표시됩니다.

### 입력 중일 때

단일 키(<kbd>N</kbd>, <kbd>/</kbd>, <kbd>?</kbd>, <kbd>Alt</kbd> 화살표)는 필드, 스택 편집기, 대화 상자에 입력하는 동안에는 작동하지 않고, 대신 해당 문자가 입력됩니다. <kbd>Mod</kbd> 키를 사용하는 단축키는 그곳에서도 작동합니다. 컨테이너의 **터미널** 탭에서는 모든 키가 컨테이너로 전달되며 어떤 단축키도 작동하지 않습니다.
