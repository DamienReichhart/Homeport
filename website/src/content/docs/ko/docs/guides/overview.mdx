## 개요

**개요** 페이지는 모든 호스트와 [클러스터](/docs/clusters/)를 함께 보여 주는 유일한 페이지입니다. Homeport를 시작하면 이 페이지가 열립니다. 위쪽의 **호스트 추가** 버튼과 **클러스터 추가** 버튼은 각각을 추가하는 페이지로 이동합니다.

### 호스트 카드

각 호스트에는 이름, 주소, 유형, 상태가 표시된 카드가 있습니다. 연결된 호스트의 카드에는 다음도 표시됩니다.

- 실행 중인 컨테이너 수와 전체 컨테이너 수, 이미지 수
- 컨테이너의 실시간 CPU 사용률(CPU 1개 기준 백분율). CPU가 8개인 호스트에서 `250%`는 CPU 2.5개가 사용 중이라는 뜻입니다.
- 호스트 전체 메모리 중 컨테이너가 사용하는 메모리

카드를 선택하면 해당 호스트로 전환합니다. 호스트가 연결되어 있으면 Homeport가 그 호스트의 **컨테이너** 페이지를 엽니다. **보드에서 이 호스트의 컨테이너 보기** 항목은 해당 호스트만 표시하는 [보드](#보드)를 엽니다.

### 클러스터 카드

호스트 카드 다음에는 클러스터마다 이름, API 서버, 상태, Kubernetes 버전이 표시된 카드가 있고, 연결된 뒤에는 준비된 Node 수와 실행 중인 Pod 수(페이지에 표시되는 Namespace 기준)도 표시됩니다. Homeport가 직접 개수를 세며, 개요 페이지가 열려 있는 동안 30초마다 다시 요청합니다. 자격 증명으로 읽을 수 없는 개수에는 대신 **허용되지 않음** 문구가 표시됩니다. 카드를 선택하면 해당 클러스터로 전환합니다.

### 선택한 클러스터

클러스터를 선택하면 카드 아래 섹션에 호스트 대신 클러스터가 표시됩니다.

<DocScreenshot
  name="cluster-overview"
  alt="호스트 카드 3개, 클러스터 카드 2개, 선택한 EKS 클러스터의 대시보드가 있는 개요 페이지: 버전, Node 5개 중 4개 준비됨, 단계별 Pod, 준비되지 않은 워크로드, 최근 경고."
  caption="eks-prod를 선택한 개요 페이지: Node 하나가 준비되지 않았고, api와 search에 Pod가 부족합니다."
/>

- **클러스터** — 버전, 플랫폼, API 서버, 페이지에 표시되는 Namespace.
- **Node** — 준비된 Node 수와, 준비되지 않은 각 Node(해당 페이지로 연결).
- **Pod** — 실행 중, 대기 중, 실패(크래시 중이거나 이미지를 풀할 수 없음), 완료된 Pod 수.
- **준비되지 않은 워크로드** — 원하는 수보다 준비된 Pod가 적은 Deployment, StatefulSet, DaemonSet(해당 페이지로 연결).
- **최근 경고** — 마지막 Warning 이벤트(각각 해당 객체로 연결). **모든 이벤트** 링크는 클러스터의 이벤트 페이지를 엽니다.

자격 증명으로 읽을 수 없는 부분은 그렇다고 표시되며, 나머지 부분은 그대로 표시됩니다.

### 선택한 호스트

카드 아래에는 선택한 호스트의 섹션이 다음을 보여 줍니다.

- **엔진** — 이름, 버전, 운영 체제, 커널, 아키텍처, CPU와 메모리, 스토리지 드라이버, 루트 디렉터리.
- **디스크 사용량** — 이미지, 컨테이너, 볼륨, 빌드 캐시가 차지하는 공간과, 그중 사용 중인 공간, 확보할 수 있는 공간. 버전 29 미만의 Docker Engine은 보고하는 정보가 더 적습니다. 이 경우 이미지 크기는 추정치이고, 볼륨과 빌드 캐시 크기는 **—** 기호로 표시되며, 카드에 그 사실이 표시됩니다.
- **최근 이벤트** — 엔진이 보고한 마지막 몇 가지 일. **모든 이벤트** 링크는 이벤트 페이지를 엽니다.

### 정리

디스크 사용량 카드의 **정리…** 버튼은 선택한 호스트에서만, 아무것도 사용하지 않는 항목을 삭제합니다. 삭제할 항목을 고릅니다.

| 옵션                          | 기본값 | 삭제 대상                                                          |
| ----------------------------- | :----: | ------------------------------------------------------------------ |
| **중지된 컨테이너**           |   켬   | 실행 중이 아닌 모든 컨테이너.                                      |
| **댕글링 이미지**             |   켬   | 빌드와 풀 후에 남은 태그 없는 레이어.                              |
| **사용하지 않는 모든 이미지** |   끔   | 댕글링 이미지와 함께, 어떤 컨테이너도 사용하지 않는 태그된 이미지. |
| **사용하지 않는 네트워크**    |   켬   | 연결된 컨테이너가 없는 사용자 지정 네트워크.                       |
| **빌드 캐시**                 |   켬   | 캐시된 빌드 레이어.                                                |
| **사용하지 않는 볼륨**        |   끔   | 어떤 컨테이너도 사용하지 않는 모든 볼륨(**데이터 포함**).          |

컨테이너가 먼저 삭제되므로, 컨테이너가 사용하던 이미지, 네트워크, 볼륨은 사용하지 않는 것으로 간주됩니다. 그런 다음 Homeport가 확보한 공간을 알려 줍니다.

<Aside type="danger">
  **사용하지 않는 볼륨** 옵션은 이름 있는 볼륨을 포함해 데이터를 삭제하며, 되돌릴 수 없습니다. 이
  옵션을 선택하면 마지막 확인을 위해 버튼에 **볼륨 데이터를 포함해 삭제** 문구가 표시됩니다.
</Aside>

## 보드

사이드바 두 번째 항목인 **보드** 페이지는 연결된 모든 호스트의 컨테이너를 하나의 표에 나열합니다. 호스트를 전환하지 않고도 어디에서 무엇이 실행 중이고 무엇이 멈췄는지 볼 수 있습니다.

<DocScreenshot
  name="board"
  alt="호스트 열, 필터, 실시간 CPU와 메모리와 함께 호스트 3개의 컨테이너를 나열한 보드."
/>

- **열** — 호스트, 이름, 이미지, 상태(헬스 포함), 스택, 포트, CPU, 메모리, 생성 시각. 열 이름을 선택하면 그 열로 정렬하고, 다시 선택하면 순서를 뒤집습니다. CPU와 메모리는 실시간으로 갱신됩니다.
- **필터** — 표시할 호스트(기본값은 전체), 상태(**실행 중**, **중지됨**, **비정상**), 스택 하나, 그리고 이름, 짧은 ID, 이미지, 스택, 호스트 이름과 일치하는 검색. <kbd>/</kbd> 키를 누르면 검색으로 이동합니다. **필터 지우기** 버튼은 모든 항목을 다시 표시합니다. 컨테이너를 열었다가 돌아와도 필터는 그대로 유지됩니다.
- **작업** — 각 행에는 컨테이너 페이지와 같은 시작/중지 버튼과 메뉴가 있으며, 해당 행의 호스트에 대해 동작합니다. 한 호스트나 여러 호스트에서 여러 행을 선택해 한꺼번에 시작, 중지, 다시 시작, 삭제할 수 있습니다. 삭제할 때는 먼저 확인을 요청하고 컨테이너를 호스트별로 나열합니다.
- **컨테이너 열기** — 행을 선택하면 Homeport가 해당 호스트로 전환하고 컨테이너를 엽니다. **뒤로** 버튼을 누르면 보드로 돌아갑니다.

보드를 열지 않고 모든 호스트의 컨테이너 중 하나를 찾으려면 [명령 팔레트에서 검색](/docs/guides/keyboard/#모든-호스트-검색)하세요.

연결되지 않은 호스트(연결할 수 없거나, 사용 안 함 상태이거나, 사용자의 조치를 기다리는 호스트)는 표 위에 _nas(연결할 수 없음) 호스트는 표시되지 않습니다._ 같은 한 줄과 해당 페이지 링크로 표시되며, 나머지 호스트는 평소대로 나열됩니다. 컨테이너가 수백 개를 넘으면 화면에 보이는 행만 그리므로 보드는 계속 빠르게 동작합니다.

## 시스템 트레이

Homeport는 시스템 트레이(macOS에서는 메뉴 막대, Windows에서는 알림 영역)에 아이콘을 추가합니다. 아이콘 메뉴에는 **prod-server — 연결됨** 항목처럼 모든 호스트가 상태와 함께 나열되며, 상태가 바뀌는 즉시 갱신됩니다.

- 호스트를 고르면 창이 앞으로 나오며 해당 호스트의 개요 페이지가 표시됩니다.
- **연결할 수 없음** 상태인 호스트에는 **열기** 항목과 **다시 연결** 항목이 있는 하위 메뉴가 있으며, **다시 연결** 항목은 즉시 다시 시도합니다.
- **Homeport 열기** 항목은 창을 다시 표시하고, **호스트 추가…** 항목은 호스트를 추가하는 페이지를 열며, **종료** 항목은 언제나 Homeport를 종료합니다.

아이콘의 도구 설명은 상황을 요약해 보여 줍니다. 예: **Homeport — 호스트 4개 중 3개 연결됨**. Windows에서는 아이콘을 두 번 클릭하면 창이 열립니다.

[설정](/docs/guides/settings/#데스크톱)에서 **닫으면 시스템 트레이로 이동** 옵션을 켜면, 창을 닫을 때 Homeport가 종료되지 않고 숨겨지므로 호스트 연결이 계속 열려 있습니다. 트레이에서 다시 열거나 Homeport를 다시 실행하면 됩니다. 일부 Linux 데스크톱은 트레이 아이콘을 숨깁니다. [요구 사항](/docs/requirements/#선택-사항-시스템-트레이)을 참고하세요.

### 알림

Homeport가 실행 중인 동안에는 트레이에 숨겨져 있어도, 컨테이너가 오류로 중지되거나 메모리가 부족해지거나 비정상 상태가 될 때, 그리고 호스트에 연결할 수 없게 되거나 다시 연결될 때 운영 체제의 알림으로 알려 줍니다. 각 종류는 [설정](/docs/guides/settings/#알림)에서 켜거나 끌 수 있습니다.

## 이벤트

**이벤트** 페이지는 선택한 호스트의 엔진이 보고한 내용을 최신순으로 나열합니다. 컨테이너 시작과 중지, 이미지 풀, 볼륨 생성, 네트워크 연결 등입니다. Homeport가 이벤트를 보관하므로 Homeport를 다시 시작해도 남아 있습니다. "밤사이 무엇이 다시 시작되었나?"라는 질문에 답할 수 있습니다.

| 열       | 표시 내용                                  |
| -------- | ------------------------------------------ |
| **시각** | 발생한 시각(현지 시간).                    |
| **유형** | `container`, `image`, `volume`, `network`… |
| **동작** | `start`, `die`, `pull`, `create`…          |
| **객체** | 대상의 이름.                               |
| **스택** | 대상이 속한 스택(있는 경우).               |

동작이나 객체 이름으로 검색하거나 유형으로 필터링할 수 있습니다. 목록은 실시간으로 갱신됩니다.

  alt="엔진의 최근 이벤트를 유형, 동작, 객체, 스택과 함께 나열한 이벤트 페이지."
/>

### 보관되는 내용

- **다시 시작해도 유지됩니다.** 이벤트는 도착하는 대로 이 컴퓨터에 저장됩니다. 페이지에는 최근 1,000개가 표시되며, 맨 아래까지 스크롤하거나 **이전 이벤트 불러오기** 버튼을 누르면 1,000개씩 더 불러옵니다.
- **Homeport가 닫혀 있던 동안의 이벤트.** Homeport가 호스트에 다시 연결하면 마지막으로 보관한 이벤트 이후의 이벤트를 엔진에 요청하므로, 그동안 일어난 일이 채워집니다. 엔진이 기억하는 범위, 즉 최근 수백 개의 이벤트까지입니다. 같은 이벤트가 두 번 나열되지는 않습니다.
- **30일 동안** 보관되거나, [설정 → 데이터](/docs/guides/settings/#데이터)의 **엔진 이벤트 보관 기간** 값만큼 보관되며, 호스트당 최대 10,000개입니다. 오래된 이벤트는 매시간 삭제됩니다.

**기록 지우기** 버튼은 선택한 호스트에 보관된 모든 이벤트를 잊습니다. 새 이벤트는 계속 표시됩니다. 호스트를 삭제하면 그 호스트의 이벤트도 삭제됩니다. 엔진 자체의 이벤트는 절대 변경되지 않습니다.

볼륨을 여는 Homeport의 [도우미 컨테이너](/docs/guides/volumes-networks/#도우미-컨테이너)는 여기에 표시되지 않습니다.
