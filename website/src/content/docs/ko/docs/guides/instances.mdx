[Incus 호스트](/docs/hosts/incus/)가 실행하는 대상은 **인스턴스** 단위입니다. 인스턴스는 호스트의 커널을 공유하며 Linux 배포판 전체를 부팅하는 **시스템 컨테이너** 형태이거나, 자체 커널을 가진 **가상 머신** 형태입니다. 여기의 모든 페이지는 호스트 전환기 아래에서 고른 프로젝트를 표시합니다.

## 인스턴스 페이지

**인스턴스** 페이지는 프로젝트의 인스턴스를 유형, 상태, 이미지, 전역 주소(IPv4 먼저), 메모리, 생성 후 경과 시간과 함께 나열합니다. 이름으로 필터링하거나, 컨테이너 또는 가상 머신만 표시할 수 있습니다.

| 작업          | Incus가 하는 일                                                                                                                             |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **시작**      | 인스턴스를 부팅합니다.                                                                                                                      |
| **중지**      | 인스턴스의 시스템에 종료를 요청하고 30초를 기다립니다. 종료되지 않으면 그 사실을 알리며, **강제 중지** 버튼으로 해결합니다.                 |
| **강제 중지** | 전원 플러그를 뽑듯이 즉시 끊습니다.                                                                                                         |
| **다시 시작** | 정상적으로 종료한 다음 다시 부팅합니다.                                                                                                     |
| **정지**      | 인스턴스 안의 모든 프로세스를 일시 중지합니다. **정지 해제** 버튼으로 재개합니다.                                                           |
| **삭제**      | 함께 삭제되는 스냅샷을 알려 주며 먼저 확인을 요청합니다. 실행 중인 인스턴스는 **실행 중이므로 먼저 중지하세요** 옵션을 선택해야 삭제됩니다. |

누가 변경했든, 목록은 Incus의 이벤트를 통해 곧바로 새로 고쳐집니다.

인스턴스의 페이지에는 **개요** 탭(주소, CPU 시간, 메모리, 프로세스, 스냅샷, 그리고 각각 해당 페이지로 연결되는 프로필), 프로필이 설정한 항목에 **프로필에서** 표시가 붙는 **구성** 탭과 **장치** 탭, 그리고 Incus 자체의 인스턴스 설명을 보여 주는 **원본** 탭이 있습니다.

## 인스턴스 만들기

**새 인스턴스** 버튼(또는 <kbd>n</kbd> 키)은 이미지로 인스턴스를 만듭니다.

- **이미지 서버에서**: 기본값은 공개 서버 `https://images.linuxcontainers.org`이며, 다른 simplestreams 서버도 쓸 수 있습니다. Homeport는 서버가 호스트의 아키텍처용으로 게시하는 이미지를 컨테이너용 또는 가상 머신용으로 나열하며, 시스템, 릴리스, 별칭으로 검색할 수 있습니다. `debian/12`나 `ubuntu/24.04/cloud` 같은 별칭을 직접 입력할 수도 있습니다. Incus는 `incus launch images:debian/12` 명령처럼 이미지를 다운로드합니다.
- **이 호스트의 이미지에서**: 호스트가 이미 보관하고 있는 이미지.

**프로필** 항목을 고르고(순서대로 적용되며, 나중 프로필이 앞의 프로필을 덮어씁니다), 필요하면 **CPU**, **메모리**(`2GiB`), **루트 디스크** 크기(`20GiB`, 프로필의 루트 디스크가 있는 풀에 생성)를 지정합니다. **만든 후 시작** 옵션은 기본적으로 켜져 있습니다. 대화 상자는 다운로드와 압축 해제 과정을 Incus의 표현 그대로 보여 준 다음, 새 인스턴스를 엽니다.

이미 사용 중인 이름, 서버에 없는 이미지, 가득 찬 스토리지 풀, 하드웨어 가상화가 없는 호스트(`/dev/kvm` 없음)의 가상 머신은 각각 그 사실과 해결 방법을 알려 줍니다.

## 콘솔과 터미널

**콘솔** 탭은 인스턴스가 지금까지 텍스트 콘솔에 출력한 내용을 보여 준 다음 콘솔에 연결합니다. `incus console` 명령처럼 로그인 프롬프트나 진행 중인 부팅 과정이 표시됩니다. 가상 머신에서도 작동하며, 인스턴스의 네트워크나 SSH가 망가졌을 때도 작동합니다. 탭을 벗어나거나 **다시 연결** 버튼을 누르면 연결만 해제됩니다.

**Exec** 탭은 실행 중인 인스턴스에서 셸(bash가 있으면 bash, 없으면 sh)을 열거나, 입력한 명령을 원하는 숫자 사용자 ID와 폴더로 실행합니다. **열기** 버튼은 입력한 내용으로 새 셸이나 명령을 시작합니다. 탭을 닫으면 명령이 종료되므로, 그곳에서 시작한 것은 계속 실행되지 않습니다. 가상 머신에서 exec를 쓰려면 Incus 자체 이미지에 포함되어 부팅 시 시작되는 `incus-agent`가 필요합니다. 에이전트가 실행되기 전까지는 Homeport가 그 사실을 알리며, 콘솔 탭으로 접근할 수 있습니다.

## 스냅샷

**스냅샷** 탭은 인스턴스의 스냅샷을 생성 시각, 만료 시각, 실행 상태 포함 여부와 함께 나열합니다.

- **스냅샷 만들기** 버튼은 스냅샷에 이름을 붙이고(또는 Incus가 `snap0`, `snap1`… 같은 이름을 붙이게 하고), 삭제할 때까지 또는 하루, 일주일, 30일 동안 보관합니다. 인스턴스가 실행 중이고 `migration.stateful` 설정이 허용하면 스냅샷에 메모리를 포함할 수 있으므로, 복원하면 중단된 지점에서 이어집니다.
- **복원** 버튼은 인스턴스를 스냅샷을 만든 시점의 상태로 되돌립니다. 그 이후의 모든 변경 사항이 사라지고 실행 중인 인스턴스는 다시 시작되므로, Homeport가 먼저 확인을 요청합니다.
- **삭제** 버튼은 확인 후 스냅샷을 삭제합니다. 인스턴스는 그대로 유지됩니다.

## 이미지

**이미지** 페이지는 프로젝트가 보관하는 이미지를 별칭, 설명, 유형, 아키텍처, 크기, 추가 후 경과 시간과 함께 나열합니다. 인스턴스를 만들기 위해 Incus가 다운로드한 이미지에는 **캐시됨** 표시가 붙으며, 한동안 아무것도 사용하지 않으면 Incus가 삭제합니다.

- **이미지 가져오기** 버튼은 새 인스턴스를 만들 때처럼 고른 이미지를 이미지 서버에서 미리 다운로드합니다. **서버에서 계속 최신 상태로 유지** 옵션을 켜면 Incus가 서버에서 이미지를 새로 고치고, **여기에서도 같은 별칭 지정** 옵션을 켜면 새 인스턴스가 이름으로 이미지를 사용할 수 있습니다.
- **새로 고침** 버튼은 이미지를 가져온 곳에서 더 새로운 빌드를 가져옵니다.
- 태그 버튼은 별칭을 추가하고, 별칭의 X 표시는 별칭을 삭제합니다.
- **삭제** 버튼은 이미지를 삭제합니다. 그 이미지로 만든 인스턴스는 각자 사본을 가지고 있으므로 계속 작동합니다.

## 프로필

**프로필** 페이지는 프로젝트의 프로필을, 각 프로필이 설정하는 키와 장치 수, 그 프로필을 사용하는 인스턴스와 함께 나열합니다. 프로필의 페이지에서는 `incus profile edit` 명령처럼 설명, 구성, 장치를 YAML로 편집하며, 그 프로필을 사용하는 인스턴스로 가는 링크가 있습니다. **저장** 버튼은 Incus와 마찬가지로 변경 사항을 해당 인스턴스에 적용합니다. 페이지가 프로필을 불러온 뒤 다른 사람이 프로필을 변경했다면, 그 변경을 덮어쓰지 않도록 저장이 거부됩니다. **다시 불러오기** 버튼을 누른 다음 변경 사항을 다시 적용하세요.

**새 프로필** 버튼은 빈 프로필을 만들어 엽니다. `default` 프로필과 인스턴스가 사용 중인 프로필은 삭제할 수 없습니다.

## 스토리지

**스토리지** 페이지는 각 스토리지 풀을 드라이버, 사용률과 함께 보여 주고, 선택한 풀에서 프로젝트의 볼륨을 보여 줍니다. 인스턴스와 이미지 자체의 볼륨, 그리고 사용자 지정 볼륨이 내용, 크기, 사용처와 함께 표시됩니다.

**새 볼륨** 버튼은 지정한 크기 또는 풀의 기본 크기로 파일 시스템이나 블록 장치인 사용자 지정 볼륨을 만듭니다. 인스턴스보다 오래 남아야 하는 데이터를 위해 인스턴스에 연결합니다(`incus storage volume attach`). 사용자 지정 볼륨은 아무것도 사용하지 않을 때 삭제할 수 있습니다. 풀 자체는 `incus storage create` 명령으로 만듭니다.

## 네트워크

**네트워크** 페이지는 프로젝트에서 보이는 네트워크를, 관리형 네트워크(Incus가 만든 것)를 먼저 두고 IPv4와 IPv6 설정, NAT, 사용처와 함께 나열합니다. 네트워크의 페이지는 호스트에서의 주소, MTU, MAC 주소, 그 네트워크를 사용하는 인스턴스와 프로필, 그리고 관리형 네트워크라면 `incus network list-leases` 명령처럼 DHCP 임대 목록을 보여 줍니다.

**새 브리지** 버튼은 관리형 브리지를 만듭니다. IPv4와 IPv6는 `auto`(사용 가능한 서브넷), `none`, 또는 `10.0.5.1/24`처럼 접두사를 포함한 브리지 자체 주소입니다. **NAT** 옵션은 나가는 IPv4 트래픽을 마스커레이드합니다. 사용 중인 네트워크나 머신 자체의 인터페이스는 여기에서 삭제할 수 없습니다.
