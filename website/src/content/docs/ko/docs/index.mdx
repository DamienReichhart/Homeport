**Homeport**는 이 컴퓨터의 것이든 SSH, TLS, TCP로 연결하는 원격의 것이든 어디에 있는 Docker Engine, containerd, Incus를 관리하고, 이들이 이루는 Swarm, kubeconfig로 접근할 수 있는 Kubernetes 클러스터, 직접 지정한 Nomad 클러스터도 관리하는 데스크톱 앱으로, Docker Desktop과 같은 방식을 따릅니다. Windows, macOS, Linux에서 실행되고, 무료이며, [GNU Affero General Public License 버전 3](https://github.com/DamienReichhart/Homeport/blob/main/LICENSE)에 따른 오픈 소스입니다.

Homeport는 컨테이너를 직접 실행하지 않습니다. 이미 가지고 있는 엔진, 즉 **호스트**에 연결하여 그 위의 모든 것, 곧 컨테이너, 이미지, 볼륨, 네트워크, Compose **스택**을 하나의 창에서 다룰 수 있게 합니다. 또한 Kubernetes와 Nomad **클러스터**에 연결하여 그 위에서 실행되는 것을 확인하고 관리할 수 있습니다. 호스트나 클러스터에는 아무것도 설치하지 않습니다.

## 이 문서의 구성

- **시작하기** — [Homeport를 설치](/docs/installation/)한 다음 [빠른 시작](/docs/quick-start/)을 따라 첫 번째 호스트에 연결합니다.
- **호스트** — 연결 종류별 작동 방식: [로컬 엔진](/docs/hosts/local/), [SSH](/docs/hosts/ssh/), [TLS와 TCP](/docs/hosts/tls-tcp/). 그리고 전용 페이지가 있는 엔진인 [containerd](/docs/hosts/containerd/)와 [Incus](/docs/hosts/incus/).
- **클러스터** — kubeconfig에서 [Kubernetes 클러스터를 추가](/docs/clusters/)하고 살펴보고 변경하는 방법, [Helm 릴리스](/docs/clusters/helm/), [Nomad 클러스터](/docs/clusters/nomad/).
- **Homeport 사용하기** — 앱의 각 페이지에 대한 안내.
- **참고 자료** — [보안](/docs/reference/security/), [데이터와 백업](/docs/reference/data-and-backups/), [업데이트](/docs/reference/updating/), [문제 해결](/docs/reference/troubleshooting/), [자주 묻는 질문](/docs/reference/faq/), [용어집](/docs/reference/glossary/).

## 이 문서에서 쓰는 용어

Homeport는 대상을 정확한 이름으로 부르며, 이 문서도 그대로 따릅니다.

- **호스트**는 Homeport가 연결하는 엔진으로, Docker Engine이거나 Podman, containerd, Incus 같은 호환 엔진입니다. 모든 컨테이너, 이미지, 볼륨, 네트워크, 스택은 정확히 하나의 호스트에 속합니다.
- **클러스터**는 kubeconfig의 컨텍스트에서 추가하는 Kubernetes 클러스터이거나, 에이전트 중 하나의 주소로 추가하는 Nomad 클러스터입니다.
- **Swarm**은 Docker Swarm으로, 그에 속한 호스트를 통해 찾으며 따로 추가하지 않습니다.
- **스택**은 호스트에서 실행되는 Compose 프로젝트이거나 Swarm에서 실행되는 Swarm 스택입니다. **관리형 스택**은 Homeport가 compose 파일을 보관하는 스택이고, **링크된 스택**은 compose 파일을 이 컴퓨터의 폴더에 두는 스택이며, **동기화 스택**은 git 저장소를 따라가는 스택이고, **외부 스택**은 다른 방법으로 배포된 스택입니다. 외부 스택을 **관리형으로 전환**하면 Homeport에서 관리할 수 있습니다.

전체 목록은 [용어집](/docs/reference/glossary/)에 있습니다.
