Docker Engine은 소켓뿐 아니라 TCP 포트에서도 수신 대기할 수 있습니다. Homeport는 이런 엔진에 상호 TLS(Docker에서 `--tlsverify`라고 부르는 설정)로 연결하거나, 완전히 신뢰하는 네트워크에서는 일반 TCP로 연결합니다.

## TLS

상호 TLS에서는 Homeport가 서버의 인증서를 CA로 확인하고, 서버는 Homeport의 클라이언트 인증서를 확인합니다. 네트워크에 엔진을 노출하는 안전한 방법입니다.

### 필요한 것

Docker TLS 설정에서 만든 PEM 형식 파일 세 개가 필요합니다.

| 필드                  | 보통 파일 이름 | 내용                                                                    |
| --------------------- | -------------- | ----------------------------------------------------------------------- |
| **CA 인증서**         | `ca.pem`       | 서버 인증서에 서명한 인증 기관. 인증서가 여러 개 들어 있을 수 있습니다. |
| **클라이언트 인증서** | `cert.pem`     | 서버가 신뢰하는 CA가 서명한 Homeport의 인증서.                          |
| **클라이언트 키**     | `key.pem`      | 클라이언트 인증서의 개인 키(암호화되지 않은 상태).                      |

만드는 방법은 Docker 안내서 [Protect the Docker daemon socket](https://docs.docker.com/engine/security/protect-access/)에 설명되어 있습니다.

### TLS 호스트 추가

1. 호스트 전환기에서 **호스트 추가…** 항목을 선택하고 **TLS**를 선택합니다.
2. **이름**을 입력하고, **주소**를 `host:port` 형식(예: `docker.example.com:2376`)으로 입력합니다.
3. 각 인증서와 키에 PEM 텍스트를 붙여 넣거나 **파일에서 불러오기…** 버튼을 선택합니다.
4. **호스트 추가**를 선택합니다.

서버 인증서에는 입력한 호스트의 이름이 있어야 합니다. 즉 DNS 이름이나 IP 주소가 인증서의 주체 대체 이름(SAN)에 들어 있어야 하며, 그렇지 않으면 _…에 대한 보안 연결이 실패했습니다._ 메시지와 함께 연결이 실패합니다.

인증서와 키는 암호화하여 저장하므로 [OS 키체인](/docs/requirements/#선택-사항-os-키체인)이 필요합니다. 호스트를 편집할 때 필드를 비워 두면 저장된 값이 유지됩니다.

### Docker 컨텍스트에서

`docker context ls`에 이미 엔진이 있다면 **호스트 추가**의 **Docker 컨텍스트 가져오기**가 파일을 고르지 않고도 컨텍스트의 주소와 `ca.pem`, `cert.pem`, `key.pem`으로 호스트를 만듭니다. TLS 확인을 건너뛰는 컨텍스트는 가져오지 않습니다. [Docker 컨텍스트](/docs/hosts/#docker-컨텍스트)를 참고하세요.

## TCP

**TCP** 호스트는 암호화도 인증도 없이 `tcp://host:port`에 연결합니다.

<Aside type="danger" title="암호화되지 않고 인증되지 않음">
  포트에 접근할 수 있는 사람은 누구나 엔진을, 그리고 엔진을 통해 그 컴퓨터를 제어할 수 있습니다.
  로컬 VM처럼 완전히 신뢰하는 네트워크에서만 일반 TCP를 사용하세요. 그 밖에서는
  [SSH](/docs/hosts/ssh/)나 TLS를 사용하세요.
</Aside>

1. **호스트 추가…** 항목을 선택하고 **TCP**를 선택합니다.
2. **이름**을 입력하고, **주소**를 `host:port` 형식(예: `192.168.1.10:2375`)으로 입력합니다. IPv6 주소는 대괄호로 묶습니다: `[fd00::10]:2375`.
3. **호스트 추가**를 선택합니다.
