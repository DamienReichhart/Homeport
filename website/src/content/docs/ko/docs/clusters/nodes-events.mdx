## Node

**Node** 페이지에는 클러스터가 Pod를 실행하는 머신이 나열됩니다. 각 Node가 **준비됨** 상태인지(cordon된 경우 **스케줄링 사용 안 함** 표시), 역할, kubelet 버전, 내부 IP, 플랫폼, 할당 가능한 CPU와 메모리가 표시됩니다.

/>

CPU는 코어 단위(`3920m`이면 `3.92`)로, 메모리는 GB 단위로 표시됩니다. Kubernetes는 Pod에 **할당 가능** 용량을 보고하는데, kubelet과 시스템이 일부를 예약하므로 머신의 실제 용량보다 조금 적습니다. 클러스터에서 metrics-server가 실행 중이면 **CPU 사용량**과 **메모리 사용량**에 각 Node가 그중 얼마나 사용하는지 표시됩니다([CPU와 메모리](/docs/clusters/metrics/)).

Node 페이지에는 OS 이미지, 커널, 컨테이너 런타임, 주소, taint, 레이블, 그리고 Pod에 할당 가능한 양과 나란히 표시된 용량이 있습니다. 그다음 모든 Namespace에서 그 Node에서 실행 중인 **Pod**, **조건**(메모리, 디스크, PID 압박), **이벤트**, **YAML** 탭이 이어집니다. Pod 페이지에서는 해당 Node로 이동할 수 있습니다. metrics-server가 있으면 **메트릭**에 Node의 CPU와 메모리가 할당 가능량 대비 그래프로 표시됩니다([CPU와 메모리](/docs/clusters/metrics/)).

## 이벤트

<DocScreenshot
  name="cluster-events"
  alt="이벤트 페이지: 경고 세 개(백오프 중인 Pod, 풀할 수 없는 이미지, 준비되지 않은 Node)가 먼저 표시되고 그다음 정상 이벤트가 이어지며, 각각 대상 객체, 메시지, 횟수, 경과 시간이 표시됩니다."
/>

**이벤트** 페이지에는 선택한 Namespace(또는 모든 Namespace)에서 Kubernetes가 보고한 내용이 경고부터, 그다음 최신순으로 나열됩니다. 각 항목에는 이유, 관련 객체(해당 객체의 페이지로 연결), 메시지, 발생 횟수, 마지막 발생 시각이 표시됩니다. **경고** 또는 **정상** 필터를 적용하고, 이유, 객체, 메시지로 검색할 수 있습니다. 목록은 실시간으로 업데이트됩니다.

Kubernetes는 이벤트를 약 1시간 동안 보관하므로, 조용한 클러스터에서는 목록이 비어 있는 것이 정상입니다. 모든 객체의 페이지에도 자체 **이벤트** 탭이 있습니다.

## 자격 증명으로 볼 수 없는 경우

Node는 Namespace에 속하지 않으므로, 목록을 보려면 많은 사용자에게 없는 클러스터 전체 권한이 필요합니다. 이때 페이지에는 "자격 증명으로 nodes 목록을 볼 수 없습니다."라고 표시되고, 다른 모든 페이지는 계속 작동합니다.
