**Homeport** تطبيق سطح مكتب لإدارة محركات Docker أينما كانت — محرك هذا الجهاز، أو محركات بعيدة عبر SSH أو TLS أو TCP — وعناقيد Kubernetes التي يصل إليها ملف kubeconfig الخاص بك، على غرار Docker Desktop. يعمل على Windows وmacOS وLinux، وهو مجاني ومفتوح المصدر بموجب [GNU Affero General Public License, version 3](https://github.com/DamienReichhart/Homeport/blob/main/LICENSE).

لا يشغّل Homeport الحاويات بنفسه. بل يتصل بمحركات Docker الموجودة لديك، وتُسمّى **المضيفات**، ويمنحك نافذة واحدة لكل ما عليها: الحاويات والصور ووحدات التخزين والشبكات و**مكدسات** Compose. ويتصل أيضًا بـ**عناقيد** Kubernetes الموجودة في ملف kubeconfig، لتتصفح ما يعمل عليها.

## المصطلحات التي نستخدمها

يسمّي Homeport الأشياء بدقة، وتتبعه الوثائق في ذلك:

- **المضيف** محرك Docker يتصل به Homeport. تنتمي كل حاوية وصورة ووحدة تخزين وشبكة ومكدس إلى مضيف واحد بالضبط.
- **العنقود** عنقود Kubernetes يتصل به Homeport، ويُضاف من سياق في ملف kubeconfig الخاص بك.
- **المكدس** مشروع Compose يعمل على مضيف. **المكدس المُدار** هو المكدس الذي يحتفظ Homeport بملف compose الخاص به؛ و**المكدس المرتبط** يحتفظ بملفات compose الخاصة به في مجلد على هذا الكمبيوتر؛ و**المكدس الخارجي** نُشر بطريقة أخرى. يمكنك **تبنّي** مكدس خارجي لإدارته.

يحتوي [المسرد](/docs/reference/glossary/) على القائمة الكاملة.
