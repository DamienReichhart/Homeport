**Homeport** تطبيق سطح مكتب لإدارة محركات Docker وcontainerd وIncus أينما كانت — محرك هذا الجهاز، أو محركات بعيدة عبر SSH أو TLS أو TCP — والـ Swarms التي تشكّلها، وعناقيد Kubernetes التي يصل إليها ملف kubeconfig الخاص بك وعناقيد Nomad التي تحددها، على غرار Docker Desktop. يعمل على Windows وmacOS وLinux، وهو مجاني ومفتوح المصدر بموجب [GNU Affero General Public License, version 3](https://github.com/DamienReichhart/Homeport/blob/main/LICENSE).

لا يشغّل Homeport الحاويات بنفسه. بل يتصل بالمحركات الموجودة لديك، وتُسمّى **المضيفات**، ويمنحك نافذة واحدة لكل ما عليها: الحاويات والصور ووحدات التخزين والشبكات و**مكدسات** Compose. ويتصل أيضًا بـ**عناقيد** Kubernetes وNomad، لترى ما يعمل عليها وتديره. لا يُثبَّت أي شيء على مضيف أو عنقود.

## المصطلحات التي نستخدمها

يسمّي Homeport الأشياء بدقة، وتتبعه الوثائق في ذلك:

- **المضيف** محرك يتصل به Homeport: محرك Docker أو محرك متوافق معه مثل Podman أو containerd أو Incus. تنتمي كل حاوية وصورة ووحدة تخزين وشبكة ومكدس إلى مضيف واحد بالضبط.
- **العنقود** عنقود Kubernetes، يُضاف من سياق في ملف kubeconfig الخاص بك، أو عنقود Nomad، يُضاف بعنوان أحد وكلائه.
- **Swarm** هو Docker Swarm، يُعثر عليه عبر المضيفات التي تنتمي إليه ولا يُضاف وحده أبدًا.
- **المكدس** مشروع Compose يعمل على مضيف، أو مكدس swarm يعمل على Swarm. **المكدس المُدار** هو المكدس الذي يحتفظ Homeport بملف compose الخاص به؛ و**المكدس المرتبط** يحتفظ بملفات compose الخاصة به في مجلد على هذا الكمبيوتر؛ و**المكدس المتزامن** يتابع مستودع git؛ و**المكدس الخارجي** نُشر بطريقة أخرى. يمكنك **تبنّي** مكدس خارجي لإدارته.

يحتوي [المسرد](/docs/reference/glossary/) على القائمة الكاملة.
