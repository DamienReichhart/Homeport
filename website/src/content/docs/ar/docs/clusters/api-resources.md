لدى Homeport صفحات خاصة به لأحمال العمل وPods وServices وIngresses وConfigMaps وSecrets وNodes والأحداث. أما **موارد API**، في الشريط الجانبي للعنقود، فتغطي كل ما عدا ذلك: PersistentVolumes ومطالباتها، وNetworkPolicies، وServiceAccounts وRBAC، والموارد التي تضيفها المشغّلات (operators) عبر CRDs الخاصة بها — Certificates الخاصة بـ cert-manager، وApplications الخاصة بـ Argo CD، وServiceMonitors الخاصة بـ Prometheus.

## العثور على نوع

يسرد عمود الأنواع، في جانب الصفحة، كل نوع يقدّمه العنقود، مجمّعًا حسب مجموعة API (`core` أولًا)، بالإصدار المفضل لكل مجموعة، كما يفعل `kubectl api-resources`. ابحث حسب النوع أو صيغة الجمع أو المجموعة، أو اكتب اسمًا مختصرًا: `pvc`، `netpol`، `sa`، `cert`.

يميّز قفلٌ الأنواعَ التي لا يمكنك سردها: تلك التي لا يُسمح لبيانات اعتمادك بسردها في الـ Namespace المختارة (كما يخبر العنقود Homeport عبر `SelfSubjectRulesReview`)، والأنواع القليلة التي لا يستطيع API الخاص بها السرد إطلاقًا. يوضح فتح أحدها السبب. بعض العناقيد، مثل تلك التي يكون مفوّضها webhook، لا تستطيع الإخبار بذلك؛ فلا يُميَّز حينها أي شيء، والقائمة التي تُرفض توضح ذلك.

يؤدي تثبيت CRD أو إزالته إلى تحديث القائمة تلقائيًا؛ ويعيد **تحديث** قراءتها.

## سرد الكائنات

اختر نوعًا فتُسرد كائناته بالأعمدة نفسها التي يعرضها `kubectl get`: يحدد خادم API هذه الأعمدة، بما في ذلك `additionalPrinterColumns` الخاصة بـ CRD، لذا تعرض Certificates الخاصة بـ cert-manager **Ready** و**Secret** و**Age** كما تفعل في الطرفية. تتابع القائمة التغييرات مباشرةً، عبر watch.

للأنواع التي تنتمي إلى Namespace منتقي الـ Namespace، كما في صفحات Homeport الأخرى؛ ومع **كل Namespaces**، يُضاف عمود **Namespace**.

## صفحة الكائن

انقر على كائن لفتح صفحته:

- **نظرة عامة**: الـ Namespace الخاصة به، والكائنات التي تملكه — مرتبطةً بصفحاتها — وعمره، وتسمياته وتعليقاته التوضيحية.
- **الشروط**، عندما تحتوي `status` الخاصة به عليها، كما في صفحات Homeport الخاصة.
- **الأحداث** المتعلقة به، و**YAML** الخاص به، دون `managedFields`.

عندما يسمح نوعه بذلك، يفتح **تحرير** YAML الخاص به لتغييره عبر معاينة وتطبيق من جانب الخادم (راجع [تطبيق YAML وتحريره](/docs/clusters/yaml/))، ويزيله **حذف** بعد تأكيد يذكر اسمه واسم العنقود (راجع [الحذف](/docs/clusters/actions/#الحذف)). وفي القائمة، حدّد عدة كائنات لحذفها معًا.
