**العنقود** هو عنقود Kubernetes، أو [عنقود Nomad](/docs/clusters/nomad/)، يتصل به Homeport عبر واجهته البرمجية API. يتناول هذا القسم عناقيد Kubernetes؛ أما عناقيد Nomad فلها [صفحتها الخاصة](/docs/clusters/nomad/). عنقود Kubernetes هو عنقود يصل إليه Homeport عبر خادم API الخاص به. تضيفه من سياق في ملف kubeconfig — الملف الذي يستخدمه `kubectl` بالفعل — لذا لا توجد بيانات اعتماد جديدة لإنشائها، ولا يثبّت Homeport أي شيء على العنقود: فهو يتحدث فقط مع Kubernetes API الذي يصل إليه ملف kubeconfig بالفعل، بالصلاحيات التي تمنحها بيانات اعتماده.

تظهر العناقيد بجانب مضيفاتك في المبدّل أعلى الشريط الجانبي. يؤدي تحديد أحدها إلى عرض الصفحات الخاصة به — **أحمال العمل**، و**Pods**، و**الشبكة**، و**التكوين**، و**Nodes**، و**الأحداث**، و**موارد API**، و**تطبيق YAML**، و**Helm**، و**إعادة توجيه المنافذ** — ولوحته في [نظرة عامة](/docs/guides/overview/#العنقود-المحدد)؛ ويعيد تحديد مضيف عرض صفحات المضيف.

## ما يمكنك فعله

يمكنك أن ترى ما يعمل على العنقود وما إذا كان سليمًا، مباشرةً، وأن تنفّذ مهام `kubectl` اليومية من Homeport:

1. [أضف عنقودًا](#إضافة-عنقود) من ملف kubeconfig، أو [عنقودًا محليًا](/docs/clusters/local/) بنقرة واحدة؛ وتسجّل العناقيد السحابية الدخول عبر [مكوّن exec الإضافي](/docs/clusters/exec-plugins/) الخاص بها.
2. تصفّح [أحمال العمل وPods](/docs/clusters/workloads/) الخاصة به، و[Services وIngresses وConfigMaps وSecrets](/docs/clusters/networking-config/)، و[Nodes والأحداث](/docs/clusters/nodes-events/)، و[أي مورد API آخر](/docs/clusters/api-resources/)، بما في ذلك الموارد المخصصة.
3. اقرأ [سجلات Pod أو حمل عمل وافتح طرفية](/docs/clusters/logs-exec/) في حاوية، و[أعد توجيه منفذ](/docs/clusters/port-forward/) إلى هذا الكمبيوتر.
4. [غيّر عدد النسخ، وأعد التشغيل، واحذف](/docs/clusters/actions/)، و[طبّق YAML أو حرّره](/docs/clusters/yaml/) مع معاينة ما يتغير.
5. اسرد [إصدارات Helm](/docs/clusters/helm/) وثبّتها ورقّها وتراجع عنها وألغِ تثبيتها، وأدِر مستودعات المخططات الخاصة بـ helm، باستخدام `helm` CLI على هذا الكمبيوتر.

يذهب كل تغيير إلى Kubernetes API بصلاحيات بيانات اعتمادك، وكل ما يزيل شيئًا أو يستبدله يسألك أولًا، مع ذكر اسم العنقود.

## إضافة عنقود

/>

اختر **إضافة عنقود…** في المبدّل، أو **إضافة عنقود** في صفحة العناقيد. تُعرض [العناقيد المحلية](/docs/clusters/local/) — Docker Desktop وOrbStack وRancher Desktop وkind وk3d وminikube — في الأعلى، بنقرة واحدة لكل منها. يصبح كل سياق تختاره عنقودًا يحمل اسم السياق؛ ويمكنك إعادة تسميته قبل الاستيراد أو بعده.

- يقرأ **من ملف kubeconfig على هذا الجهاز** الملفات المدرجة في `KUBECONFIG`، مدمجةً كما يدمجها `kubectl`، أو `~/.kube/config` عندما لا يكون `KUBECONFIG` معيّنًا. ويُختار السياق الحالي نيابةً عنك.
- يقرأ **لصق ملف kubeconfig** النص الذي تلصقه، في الذاكرة فقط: لا يُحفظ أبدًا كملف. يجب أن تكون الملفات التي يشير إليها (`certificate-authority: /…`) مسارات كاملة؛ والأبسط أن تلصق ملفًا تكون كل محتوياته مضمّنة فيه:

  ```bash
  kubectl config view --raw --flatten --minify
  ```

يعرض كل سياق خادم API الخاص به، والـ Namespace الخاصة به، وطريقة تسجيل دخول مستخدمه — **شهادة العميل** أو **رمز** أو **OpenID Connect** أو **مكوّن exec الإضافي (aws)** للعنقود السحابي — لتميّز العنقود المحلي من عنقود الإنتاج قبل استيراده. حدّد السياقات التي تريدها؛ يحصل كل منها على حقل للاسم، معبّأ باسم السياق. يستحسن إعادة تسمية أسماء ARN الطويلة مثل `arn:aws:eks:…:cluster/prod` إلى اسم قصير مثل `eks-prod`: فالاسم هو ما يعرضه المبدّل و«نظرة عامة».

لا يمكن استيراد سياق صار عنقودًا بالفعل مرتين: يعرض Homeport بدلًا من ذلك **تحديثه**. والسياق الذي لا يمكن استخدامه يوضح السبب، مثل مستخدم يكون `auth-provider` الخاص به `gcp` أو `azure`، وهما ما أزاله Kubernetes (حوّله إلى `gke-gcloud-auth-plugin` أو `kubelogin`، كما يتطلب `kubectl` الآن).

يمكن للمستخدمين تسجيل الدخول بشهادة عميل، أو رمز (أو `tokenFile`)، أو اسم مستخدم وكلمة مرور، أو `auth-provider` من نوع OpenID Connect (يُحدَّث رمز المعرّف الخاص به في الذاكرة)، أو مكوّن exec إضافي.

## ما يُخزَّن وأين

| يُحفظ بنص واضح في قاعدة بيانات Homeport                          | يُحفظ مشفّرًا فقط (مثل مفاتيح SSH)                                 |
| ---------------------------------------------------------------- | ------------------------------------------------------------------ |
| الاسم، وعنوان URL لخادم API، والـ Namespace الخاصة بالسياق       | شهادة CA، وشهادة العميل ومفتاحه                                    |
| طريقة تسجيل دخول مستخدمه (شهادة، رمز…)، والسياق الذي استُورد منه | الرمز أو كلمة المرور، ورموز OIDC، ووسائط مكوّن exec الإضافي وبيئته |

تُقرأ الملفات التي يشير إليها ملف kubeconfig مرة واحدة، عند الاستيراد، وتُخزَّن مشفّرة مع البقية. لا يُغيَّر ملف kubeconfig الخاص بك أبدًا. وبدون سلسلة مفاتيح نظام التشغيل، لا يستطيع Homeport تخزين بيانات الاعتماد ولن يضيف عنقودًا؛ راجع [الأمان وبياناتك](/docs/reference/security/).

## التحديث من kubeconfig

يمنح kind وk3d وminikube العنقود شهادات جديدة في كل مرة يعيدون فيها إنشاءه، وتُجدَّد بيانات الاعتماد السحابية. يعيد **التحديث من kubeconfig** في صفحة العنقود قراءة سياقه — من ملف kubeconfig على هذا الجهاز، أو من ملف kubeconfig تلصقه مجددًا إذا كان قد لُصق — ويحتفظ باسمه، ويعيد الاتصال.

## إدارة العناقيد

- يسرد **إدارة العناقيد** في المبدّل كل عنقود مع حالته وخادم API الخاص به وطريقة تسجيل دخوله.
- في صفحة العنقود، يفصل مفتاح **مفعّل** العنقود دون نسيانه، ويعيد **إعادة الاتصال** المحاولة فورًا، ويغيّر **إعادة التسمية** اسمه في Homeport فقط.
- ينسى **إزالة العنقود** العنقودَ وبيانات اعتماده المخزنة. لا يتغير شيء على العنقود ولا في ملف kubeconfig الخاص بك.

يجب أن تكون أسماء العناقيد فريدة، بغض النظر عن حالة الأحرف.

## الحالات

| الحالة                    | المعنى                                                                                      |
| ------------------------- | ------------------------------------------------------------------------------------------- |
| **متصل**                  | يجيب خادم API؛ ويظهر إصدار Kubernetes الخاص به بجانبه.                                      |
| **جارٍ الاتصال**          | يحاول Homeport الوصول إليه.                                                                 |
| **يتعذّر الوصول إليه**    | لم يُجب خادم API. يعيد Homeport المحاولة تلقائيًا، منتظرًا ثانية واحدة ثم حتى دقيقة.        |
| **تم رفض الوصول**         | رفض خادم API بيانات الاعتماد. تحقق من أن `kubectl` يعمل مع السياق، ثم حدّث العنقود.         |
| **إعداد غير صحيح**        | شيء لا يمكن إصلاحه إلا من جهتك، مثل شهادة غير مطابقة. ينتظر Homeport حتى تصلحه.             |
| **فُقدت بيانات الاعتماد** | اختفى مفتاح سلسلة مفاتيح نظام التشغيل الذي يحميها؛ حدّث العنقود من ملف kubeconfig الخاص به. |
| **معطّل**                 | أُوقف باستخدام مفتاح **مفعّل**.                                                             |

يُفحص العنقود المتصل كل 15 ثانية، لذا فإن العنقود الذي يختفي يُظهر ذلك ويعيد الاتصال تلقائيًا عند عودته، مثل المضيف.
