**Homeport** कहीं भी चल रहे Docker Engine, containerd और Incus को प्रबंधित करने के लिए एक डेस्कटॉप ऐप है — इस मशीन का इंजन, या SSH, TLS या TCP पर रिमोट इंजन — और उनसे बने Swarm, और साथ ही वे Kubernetes क्लस्टर जिन तक आपका kubeconfig पहुँचता है और वे Nomad क्लस्टर जिनका आप नाम देते हैं, Docker Desktop की तर्ज़ पर। यह Windows, macOS और Linux पर चलता है, मुफ़्त है, और [GNU Affero General Public License, version 3](https://github.com/DamienReichhart/Homeport/blob/main/LICENSE) के तहत ओपन सोर्स है।

Homeport ख़ुद कंटेनर नहीं चलाता। यह आपके पास पहले से मौजूद इंजन से कनेक्ट होता है, जिन्हें **होस्ट** कहा जाता है, और उन पर मौजूद हर चीज़ के लिए आपको एक ही विंडो देता है: कंटेनर, इमेज, वॉल्यूम, नेटवर्क और Compose **स्टैक**। यह Kubernetes और Nomad **क्लस्टर** से भी कनेक्ट होता है, ताकि आप देख सकें कि उन पर क्या चल रहा है और उसे प्रबंधित कर सकें। किसी होस्ट या क्लस्टर पर कुछ भी इंस्टॉल नहीं होता।

## यह दस्तावेज़ कैसे व्यवस्थित है

- **शुरुआत** — [Homeport इंस्टॉल करें](/docs/installation/), फिर अपना पहला होस्ट कनेक्ट करने के लिए [क्विक स्टार्ट](/docs/quick-start/) का पालन करें।
- **होस्ट** — हर तरह का कनेक्शन कैसे काम करता है: [लोकल इंजन](/docs/hosts/local/), [SSH](/docs/hosts/ssh/), और [TLS और TCP](/docs/hosts/tls-tcp/); और वे इंजन जिनके अपने पेज हैं, [containerd](/docs/hosts/containerd/) और [Incus](/docs/hosts/incus/)।
- **क्लस्टर** — kubeconfig से [Kubernetes क्लस्टर जोड़ना](/docs/clusters/), उन्हें ब्राउज़ करना और बदलना, [Helm रिलीज़](/docs/clusters/helm/), और [Nomad क्लस्टर](/docs/clusters/nomad/)।
- **Homeport का इस्तेमाल** — ऐप के हर पेज की गाइड।
- **संदर्भ** — [सुरक्षा](/docs/reference/security/), [आपका डेटा और बैकअप](/docs/reference/data-and-backups/), [अपडेट करना](/docs/reference/updating/), [समस्या निवारण](/docs/reference/troubleshooting/), [अक्सर पूछे जाने वाले प्रश्न](/docs/reference/faq/) और [शब्दावली](/docs/reference/glossary/)।

## हम जिन शब्दों का इस्तेमाल करते हैं

Homeport चीज़ों को सटीक नाम देता है, और यह दस्तावेज़ भी उन्हीं का पालन करता है:

- **होस्ट** एक इंजन है जिससे Homeport कनेक्ट होता है: Docker Engine या उसके साथ संगत कोई इंजन, जैसे Podman, containerd या Incus। हर कंटेनर, इमेज, वॉल्यूम, नेटवर्क और स्टैक ठीक एक होस्ट का होता है।
- **क्लस्टर** एक Kubernetes क्लस्टर है, जिसे आपके kubeconfig के किसी context से जोड़ा जाता है, या एक Nomad क्लस्टर, जिसे उसके किसी agent के पते से जोड़ा जाता है।
- **Swarm** एक Docker Swarm है, जिसे उन होस्ट के ज़रिए खोजा जाता है जो उसका हिस्सा हैं, और जिसे कभी अलग से नहीं जोड़ा जाता।
- **स्टैक** किसी होस्ट पर चल रहा एक Compose प्रोजेक्ट है, या किसी Swarm पर चल रहा swarm स्टैक। **प्रबंधित स्टैक** वह है जिसकी compose फ़ाइल Homeport रखता है; **लिंक्ड स्टैक** अपनी compose फ़ाइलें इस कंप्यूटर के एक फ़ोल्डर में रखता है; **सिंक्ड स्टैक** किसी git रिपॉज़िटरी को फ़ॉलो करता है; **बाहरी स्टैक** किसी और तरीक़े से डिप्लॉय किया गया था। किसी बाहरी स्टैक को प्रबंधित करने के लिए आप उसे **अपना** सकते हैं।
