## अपडेट करना

Homeport कैसे अपडेट होता है, यह इस पर निर्भर करता है कि आपने उसे कैसे इंस्टॉल किया।

### Windows, macOS और AppImage

Homeport शुरू होने पर और हर 6 घंटे में नए संस्करण की जाँच करता है। जब कोई नया संस्करण आता है, तो विंडो के ऊपर एक बार यह बताता है: [changelog](/changelog/) पढ़ने के लिए **नया क्या है** चुनें, या **इंस्टॉल करें और रीस्टार्ट करें**। Homeport अपडेट डाउनलोड करता है, उसका सिग्नेचर जाँचता है, उसे इंस्टॉल करता है और फिर से खुलता है। जब तक आप न चुनें, कुछ भी इंस्टॉल नहीं होता, और [आपका डेटा बना रहता है](#संस्करणों-के-पार-आपका-डेटा)।

आप **सेटिंग्स → अपडेट → अभी जाँचें** से अभी भी जाँच सकते हैं।

### Linux पैकेज

`.deb` और `.rpm` पैकेज, चाहे [क्विक इंस्टॉल](/docs/installation/#क्विक-इंस्टॉल), [मैनुअल सेटअप](/docs/installation/#मैनुअल-सेटअप) या डाउनलोड की गई फ़ाइल से इंस्टॉल किए गए हों, आपके बाकी सिस्टम के साथ Homeport पैकेज रिपॉज़िटरी से अपडेट होते हैं: आपके सामान्य सॉफ़्टवेयर अपडेट में Homeport शामिल होता है। सिर्फ़ Homeport को अपडेट करने के लिए:

जब नया संस्करण आता है तो Homeport आपको बताता है और आपके सिस्टम के लिए कमांड दिखाता है, लेकिन उसे इंस्टॉल करने का काम आपके पैकेज मैनेजर पर छोड़ देता है।

अगर आपने Homeport रिपॉज़िटरी हटा दी है, तो आपका पैकेज मैनेजर नए संस्करण नहीं देख सकता। उसे [क्विक इंस्टॉल](/docs/installation/#क्विक-इंस्टॉल) से फिर से सेट अप करें, या नया पैकेज डाउनलोड करके पुराने के ऊपर इंस्टॉल करें।

### अपडेट जाँच बंद करना

**सेटिंग्स → अपडेट → अपडेट अपने आप जाँचें** बंद करें। **अभी जाँचें** फिर भी काम करता है। एक जाँच इस वेबसाइट से एक छोटी फ़ाइल डाउनलोड करती है और आपके या आपके होस्ट के बारे में कुछ नहीं भेजती। [सुरक्षा और आपका डेटा](/docs/reference/security/#homeport-किससे-कनेक्ट-होता-है) देखें।

### 0.2.0 या उससे पहले के संस्करण से अपडेट करना

0.3.0 से पहले के संस्करण ख़ुद को अपडेट नहीं करते, और उनके Linux पैकेज रिपॉज़िटरी नहीं जोड़ते। 0.3.0 या बाद का संस्करण एक बार इंस्टॉल करें, उसी तरह जैसे आपने Homeport इंस्टॉल किया था: [डाउनलोड पेज](/download/) से, या Linux पर [क्विक इंस्टॉल](/docs/installation/#क्विक-इंस्टॉल) से। उसके बाद, अपडेट अपने-आप आते हैं।

फिर भी नए संस्करणों के बारे में जानने के लिए, GitHub पर रिपॉज़िटरी को watch करें (**Watch → Custom → Releases**), या [releases feed](https://github.com/DamienReichhart/Homeport/releases.atom) फ़ॉलो करें।

## संस्करणों के पार आपका डेटा

Homeport का हर संस्करण हर पिछले संस्करण का डेटा खोलता है, 0.1.0 तक, और कुछ भी खोए बिना उसे अपग्रेड करता है: होस्ट, स्टैक, क्लस्टर, सेटिंग्स और सीक्रेट। कोई अपडेट आपसे कभी कुछ फिर से सेट अप करने को नहीं कहता: जब कोई नया संस्करण पहली बार शुरू होता है, तो वह अपना डेटाबेस उसी जगह अपग्रेड करता है, और सब कुछ पहले की तरह कनेक्ट होता है। हर रिलीज़ को उससे पहले की हर रिलीज़ के एक नमूना डेटाबेस पर टेस्ट किया जाता है।

**पुराने संस्करण पर वापस जाना सपोर्ट नहीं होता।** एक बार किसी नए संस्करण ने आपका डेटा खोल लिया, तो कोई पुराना संस्करण उसे नहीं पढ़ सकता, और वह कोशिश भी नहीं करता: कुछ भी बदलने के बजाय वह [इंस्टॉल करने वाले संस्करण का नाम बताने वाले एक संदेश](/docs/reference/troubleshooting/#इस-डेटाबेस-का-पिछली-बार-इस्तेमाल-homeport--या-उसके-बाद-के-वर्शन-ने-किया-था) के साथ रुक जाता है। आपका डेटा वैसा ही रहता है जैसा नए संस्करण ने छोड़ा था; वह संस्करण, या उससे नया, इंस्टॉल करें, और Homeport उसे फिर से खोलता है।

**प्री-रिलीज़ आज़माने से पहले बैकअप लें।** प्री-रिलीज़ किसी भी दूसरे संस्करण की तरह डेटाबेस अपग्रेड करती है, इसलिए जिस स्टेबल रिलीज़ से आप आए हैं, वह उसे अब नहीं खोल सकती। पहले **सेटिंग्स → डेटा → बैकअप लें…** चुनें; [आपका डेटा और बैकअप](/docs/reference/data-and-backups/#homeport-में-बैकअप-लेना) देखें। स्टेबल रिलीज़ पर वापस जाने के लिए, Homeport बंद करें, `homeport.db` को [डेटा फ़ोल्डर](/docs/reference/data-and-backups/#डेटा-फ़ोल्डर) से बाहर ले जाएँ, स्टेबल रिलीज़ फिर से इंस्टॉल करें, और उस बैकअप को **रीस्टोर करें…**।

## अनइंस्टॉल करना

<Tabs syncKey="os">
<TabItem label="Windows">
**Settings → Apps → Installed apps** खोलें, **Homeport** ढूँढें, और **Uninstall** चुनें।
</TabItem>
<TabItem label="macOS">Homeport बंद करें और उसे Applications से Bin में खींचें।</TabItem>
<TabItem label="Linux">

```sh
sudo apt purge homeport       # Debian, Ubuntu
sudo dnf remove homeport      # Fedora, RHEL
sudo zypper remove homeport   # openSUSE
```

इससे Homeport रिपॉज़िटरी भी हट जाती है। Debian और Ubuntu पर, `apt remove` उसे पैकेज के बाकी कॉन्फ़िगरेशन के साथ रखता है, और `apt purge` उसे उसकी कुंजी के साथ हटा देता है। Fedora और openSUSE पर कुंजी rpm के keyring में रहती है; `rpm -q gpg-pubkey --qf '%{NAME}-%{VERSION}-%{RELEASE} %{SUMMARY}\n'` कुंजियों को सूचीबद्ध करता है, और `sudo rpm -e gpg-pubkey-<version>-<release>` Homeport की कुंजी हटाता है।

AppImage के लिए, फ़ाइल मिटा दें। उसकी मेनू एंट्री उसके साथ ग़ायब हो जाती है।

</TabItem>
</Tabs>

अनइंस्टॉल करने से आपका डेटा अपनी जगह पर रहता है, इसलिए फिर से इंस्टॉल करने पर सब कुछ वापस आ जाता है। [आपका डेटा और बैकअप](/docs/reference/data-and-backups/) बताता है कि यह कहाँ है।

### लॉगिन एंट्री

अगर **लॉगिन पर शुरू करें** चालू है, तो अनइंस्टॉल करने से पहले उसे **सेटिंग्स → डेस्कटॉप** में बंद करें: अनइंस्टॉल करने से लॉगिन एंट्री पीछे रह जाती है, जो एक ऐसे Homeport की ओर इंगित करती है जो अब नहीं है। उसे बाद में हटाने के लिए:

| सिस्टम  | लॉगिन एंट्री                                                                                                                                                     |
| ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Windows | **Task Manager → Startup apps**: **Homeport** को अक्षम करें, या `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` के तहत `Homeport` मान मिटा दें |
| macOS   | `~/Library/LaunchAgents/Homeport.plist` मिटा दें                                                                                                                 |
| Linux   | `~/.config/autostart/Homeport.desktop` मिटा दें                                                                                                                  |

## अपना डेटा हटाना

<Aside type="caution">
  इससे आपके होस्ट और क्लस्टर उनकी सहेजी गई कुंजियों, प्रमाणपत्रों और टोकन के साथ, आपके प्रबंधित,
  लिंक्ड और सिंक्ड स्टैक उनके परिवेश और डिप्लॉय इतिहास के साथ, आपके रजिस्ट्री लॉगिन, रिपॉज़िटरी और
  सेटिंग्स मिट जाते हैं। लिंक्ड स्टैक के फ़ोल्डर जहाँ हैं वहीं रहते हैं। आपके होस्ट और क्लस्टर पर
  किसी भी चीज़ को छुआ नहीं जाता। पहले एक कॉपी रखने के लिए, [उसका बैकअप
  लें](/docs/reference/data-and-backups/)।
</Aside>

1. Homeport के डेटा और लॉग फ़ोल्डर मिटा दें:

   | सिस्टम  | फ़ोल्डर                                                                               |
   | ------- | ------------------------------------------------------------------------------------- |
   | Linux   | `~/.local/share/com.homeport.app/`, `~/.config/com.homeport.app/`                     |
   | macOS   | `~/Library/Application Support/com.homeport.app/`, `~/Library/Logs/com.homeport.app/` |
   | Windows | `%APPDATA%\com.homeport.app\`, `%LOCALAPPDATA%\com.homeport.app\`                     |

2. अपने कीचेन से एन्क्रिप्शन कुंजी मिटा दें — `com.homeport.app` की एंट्री, अकाउंट `secrets-key`:
   - **macOS** — **Keychain Access** में, `com.homeport.app` खोजें और उसे मिटा दें।
   - **Windows** — **Credential Manager → Windows Credentials** में, `com.homeport.app` वाली एंट्री हटा दें।
   - **Linux** — **Passwords and Keys** (Seahorse) या KWallet में, `com.homeport.app` की एंट्री मिटा दें।

3. अपने सर्वर पर, `~/.ssh/authorized_keys` से Homeport की पब्लिक कुंजियाँ हटा दें — उनकी टिप्पणियाँ `homeport@` से शुरू होती हैं। अपने git फ़ोर्ज पर, Homeport की आपकी रिपॉज़िटरी के लिए बनाई गई डिप्लॉय कुंजियाँ हटा दें, और HTTPS पर जोड़े गए Incus सर्वर पर, Homeport का प्रमाणपत्र (`incus config trust list`, फिर `incus config trust remove`)।
