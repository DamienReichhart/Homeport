**Homeport** ist eine Desktop-App zur Verwaltung von Docker Engines, containerd und Incus, wo auch immer sie laufen – der Engine dieses Rechners oder entfernter Engines über SSH, TLS oder TCP –, der Swarms, die sie bilden, sowie der Kubernetes-Cluster, die Ihre kubeconfig erreicht, und der Nomad-Cluster, die Sie angeben, ganz im Sinne von Docker Desktop. Sie läuft unter Windows, macOS und Linux, ist kostenlos und quelloffen unter der [GNU Affero General Public License, Version 3](https://github.com/DamienReichhart/Homeport/blob/main/LICENSE).

Homeport führt selbst keine Container aus. Es verbindet sich mit den Engines, die Sie bereits haben, den sogenannten **Hosts**, und bietet Ihnen ein einziges Fenster für alles, was darauf läuft: Container, Images, Volumes, Netzwerke und Compose-**Stacks**. Außerdem verbindet es sich mit Kubernetes- und Nomad-**Clustern**, um zu sehen, was auf ihnen läuft, und es zu verwalten. Auf einem Host oder Cluster wird nichts installiert.

## Begriffe, die wir verwenden

Homeport benennt Dinge genau, und die Dokumentation folgt dem:

- Ein **Host** ist eine Engine, mit der sich Homeport verbindet: eine Docker Engine oder eine kompatible wie Podman, containerd oder Incus. Jeder Container, jedes Image, jedes Volume, jedes Netzwerk und jeder Stack gehört zu genau einem Host.
- Ein **Cluster** ist ein Kubernetes-Cluster, hinzugefügt aus einem Kontext Ihrer kubeconfig, oder ein Nomad-Cluster, hinzugefügt über die Adresse eines seiner Agenten.
- Ein **Swarm** ist ein Docker Swarm, gefunden über die Hosts, die zu ihm gehören, und nie eigens hinzugefügt.
- Ein **Stack** ist ein Compose-Projekt, das auf einem Host läuft, oder ein Swarm-Stack, der auf einem Swarm läuft. Ein **verwalteter Stack** ist einer, dessen Compose-Datei Homeport aufbewahrt; ein **verknüpfter Stack** bewahrt seine Compose-Dateien in einem Ordner auf diesem Computer auf; ein **synchronisierter Stack** folgt einem Git-Repository; ein **externer Stack** wurde auf andere Weise bereitgestellt. Sie können einen externen Stack **übernehmen**, um ihn zu verwalten.

Das [Glossar](/docs/reference/glossary/) enthält die vollständige Liste.
