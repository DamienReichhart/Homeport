Каждый релиз Homeport собирается GitHub Actions из публичного репозитория. Проверить, что скачанный вами файл — именно тот, что был собран, можно двумя способами. Пакеты для Linux и обновления к тому же подписаны и проверяются автоматически.

## Контрольные суммы

Каждый релиз содержит `SHA256SUMS.txt` с контрольной суммой SHA-256 для каждого файла. [Страница загрузки](/download/) тоже показывает контрольную сумму каждого файла. Скачайте `SHA256SUMS.txt` в ту же папку, что и установщик, затем:

<Tabs syncKey="os">
<TabItem label="Linux">

```sh
sha256sum --ignore-missing -c SHA256SUMS.txt
```

</TabItem>
<TabItem label="macOS">

```sh
shasum -a 256 --ignore-missing -c SHA256SUMS.txt
```

</TabItem>
<TabItem label="Windows">

```powershell
(Get-FileHash .\Homeport-1.0.0-windows-x64-setup.exe -Algorithm SHA256).Hash.ToLower()
```

Сравните результат со строкой установщика в `SHA256SUMS.txt`.

</TabItem>
</Tabs>

`OK` рядом с именем файла означает, что он совпадает.

## Происхождение сборки

Контрольная сумма доказывает, что файл не был повреждён или подменён после публикации контрольной суммы. [Аттестация происхождения сборки](https://docs.github.com/actions/security-for-github-actions/using-artifact-attestations) идёт дальше: она подписана GitHub и фиксирует репозиторий, коммит и процесс, создавшие файл.

При установленном [GitHub CLI](https://cli.github.com):

```sh
gh attestation verify Homeport-1.0.0-windows-x64-setup.exe --repo DamienReichhart/Homeport
```

Успешная проверка выводит процесс и коммит, из которых собран файл.

## Подписи пакетов

Репозиторий пакетов Homeport и каждый `.rpm` подписаны ключом пакетов Homeport (RSA 4096):

**Отпечаток:** <SigningKeyFingerprint />

`apt`, `dnf` и `zypper` проверяют эти подписи при каждом обновлении и отклоняют пакеты и данные репозитория, которые им не соответствуют. Чтобы проверить скачанный ключ или файл `.rpm`:

<Code code={`curl -fsSL ${KEY_URL} | gpg --show-keys --with-fingerprint`} lang="sh" />

```sh
sudo rpm --import homeport.asc   # once
rpm -K Homeport-<version>-linux-x64.rpm
```

Для подписанного пакета `rpm -K` выводит `digests signatures OK`. Сам файл `.deb` не подписан: его покрывает подписанный индекс репозитория, а скачанный вручную — его контрольная сумма и аттестация.

## Подписи обновлений

Каждое обновление, которое устанавливает встроенное средство обновления, подписано отдельным ключом обновлений Homeport, открытая часть которого встроена в Homeport. Перед установкой Homeport проверяет подпись и то, что она сделана для объявленной версии, и отклоняет всё остальное, даже если оно пришло с правильного адреса.

## Подпись кода

Приложение для macOS подписано ad-hoc, а установщики для Windows пока не подписаны коммерческим сертификатом, поэтому macOS и Windows просят подтвердить первый запуск. Как это сделать, показано на странице [Установка](/docs/installation/). Обновления, установленные изнутри Homeport, больше не спрашивают.
