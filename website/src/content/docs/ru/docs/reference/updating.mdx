## Обновление

Как обновляется Homeport, зависит от того, как вы его установили.

### Windows, macOS и AppImage

Homeport проверяет наличие новой версии при запуске и каждые 6 часов. Когда она выходит, об этом сообщает полоса вверху окна: выберите **Что нового**, чтобы прочитать [список изменений](/changelog/), или **Установить и перезапустить**. Homeport скачивает обновление, проверяет его подпись, устанавливает и открывается снова. Ничего не устанавливается, пока вы этого не выберете, а ваши хосты, стеки и настройки сохраняются.

Проверить можно и прямо сейчас: **Настройки → Обновления → Проверить сейчас**.

### Пакеты для Linux

Пакеты `.deb` и `.rpm`, установленные [быстрой установкой](/docs/installation/#быстрая-установка), [ручной настройкой](/docs/installation/#ручная-настройка) или из скачанного файла, обновляются из репозитория пакетов Homeport вместе с остальной системой: обычные обновления ПО включают и Homeport. Чтобы обновить только Homeport:

  {MANUAL_SETUP.map((setup) => (
    <TabItem label={setup.label}>

Homeport сообщает о выходе новой версии и показывает команду для вашей системы, но установку оставляет менеджеру пакетов.

Если вы удалили репозиторий Homeport, менеджер пакетов не видит новых версий. Подключите его снова [быстрой установкой](/docs/installation/#быстрая-установка) или скачайте новый пакет и установите его поверх старого.

### Отключение проверки обновлений

Выключите **Настройки → Обновления → Проверять обновления автоматически**. **Проверить сейчас** продолжает работать. Проверка скачивает один небольшой файл с этого сайта и ничего не отправляет ни о вас, ни о ваших хостах. См. [безопасность и ваши данные](/docs/reference/security/#к-чему-подключается-homeport).

### Обновление с 0.2.0 или более ранних версий

Версии до 0.3.0 не обновляются сами, а их пакеты для Linux не добавляют репозиторий. Один раз установите 0.3.0 или новее тем же способом, которым устанавливали Homeport: со [страницы загрузки](/download/) или, в Linux, [быстрой установкой](/docs/installation/#быстрая-установка). После этого обновления будут приходить сами.

Чтобы в любом случае узнавать о новых версиях, следите за репозиторием на GitHub (**Watch → Custom → Releases**) или подпишитесь на [ленту релизов](https://github.com/DamienReichhart/Homeport/releases.atom).

## Удаление

<Tabs syncKey="os">
<TabItem label="Windows">
Откройте **Параметры → Приложения → Установленные приложения**, найдите **Homeport** и выберите **Удалить**.
</TabItem>
<TabItem label="macOS">Завершите Homeport и перетащите его из папки «Программы» в Корзину.</TabItem>
<TabItem label="Linux">

```sh
sudo apt purge homeport       # Debian, Ubuntu
sudo dnf remove homeport      # Fedora, RHEL
sudo zypper remove homeport   # openSUSE
```

Это также удаляет репозиторий Homeport. В Debian и Ubuntu `apt remove` сохраняет его вместе с остальной конфигурацией пакета, а `apt purge` удаляет его вместе с ключом. В Fedora и openSUSE ключ остаётся в связке ключей rpm; `rpm -q gpg-pubkey --qf '%{NAME}-%{VERSION}-%{RELEASE} %{SUMMARY}\n'` перечисляет ключи, а `sudo rpm -e gpg-pubkey-<version>-<release>` удаляет ключ Homeport.

Для AppImage удалите файл. Его пункт меню исчезнет вместе с ним.

</TabItem>
</Tabs>

Удаление оставляет ваши данные на месте, так что после повторной установки всё вернётся.

### Пункт автозапуска

Если включено **Запускать при входе в систему**, выключите это в **Настройки → Рабочий стол** перед удалением: удаление оставляет пункт автозапуска, указывающий на уже удалённый Homeport. Чтобы удалить его потом:

| Система | Пункт автозапуска                                                                                                                                              |
| ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Windows | **Диспетчер задач → Автозагрузка**: отключите **Homeport** или удалите значение `Homeport` в `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` |
| macOS   | Удалите `~/Library/LaunchAgents/Homeport.plist`                                                                                                                |
| Linux   | Удалите `~/.config/autostart/Homeport.desktop`                                                                                                                 |

## Удаление ваших данных

<Aside type="caution">
  Это удаляет ваши хосты, их сохранённые ключи и сертификаты, определения ваших управляемых стеков,
  ваши связанные стеки и историю их развёртываний. Папки связанных стеков остаются на месте. На
  ваших хостах ничего не затрагивается.
</Aside>

1. Удалите папки данных и журналов Homeport:

   | Система | Папки                                                                                 |
   | ------- | ------------------------------------------------------------------------------------- |
   | Linux   | `~/.local/share/com.homeport.app/`, `~/.config/com.homeport.app/`                     |
   | macOS   | `~/Library/Application Support/com.homeport.app/`, `~/Library/Logs/com.homeport.app/` |
   | Windows | `%APPDATA%\com.homeport.app\`, `%LOCALAPPDATA%\com.homeport.app\`                     |

2. Удалите ключ шифрования из связки ключей — запись для `com.homeport.app`:
   - **macOS** — в приложении **Связка ключей** найдите `com.homeport.app` и удалите запись.
   - **Windows** — в **Диспетчер учётных данных → Учётные данные Windows** удалите запись, содержащую `com.homeport.app`.
   - **Linux** — в **Пароли и ключи** (Seahorse) или KWallet удалите запись для `com.homeport.app`.

3. На своих серверах удалите открытые ключи Homeport из `~/.ssh/authorized_keys` — их комментарии начинаются с `homeport@`.
