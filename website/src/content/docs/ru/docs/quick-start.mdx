Это руководство проведёт вас от свежей установки до запуска контейнера на первом хосте.

## 1. Добавьте хост

При первом открытии Homeport показывает экран **Добро пожаловать в Homeport**.

Если на этом компьютере работает движок Docker, он появляется в разделе **Найдено на этом компьютере** со своей версией, например `Docker Desktop · Engine 27.3.1`. Выберите **Добавить** рядом с ним — и подключение готово; переходите к [шагу 2](#2-осмотритесь).

Чтобы вместо этого подключиться к удалённому движку, выберите **Добавить ещё хост**:

<Steps>

1. Выберите способ подключения: **SSH**, **TLS**, **TCP** или **Локальный сокет**. Для сервера обычно выбирают SSH.

2. Дайте хосту понятное вам **Имя**, например `production`.

3. Заполните параметры подключения. Для SSH это **Сервер**, **Порт**, **Пользователь** и, если Docker находится не в стандартном месте, **Путь к удалённому сокету**.

4. Выберите **Добавить хост**. Homeport откроет страницу хоста и начнёт подключение.

</Steps>

При первом подключении хосту SSH нужны ещё две вещи. Они подробно описаны на странице [Хосты SSH](/docs/hosts/ssh/):

- **Доверьтесь ключу сервера.** Homeport показывает отпечаток сервера; сверьте его и выберите **Доверять этому ключу**.
- **Авторизуйте ключ Homeport.** Скопируйте команду из раздела **Авторизуйте Homeport на сервере**, выполните её на сервере, затем выберите **Переподключиться**.

Когда состояние сменится на **Подключён**, всё готово.

## 2. Осмотритесь

На боковой панели есть страница для каждого вида ресурсов, и все они показывают хост, выбранный в **переключателе хостов** вверху боковой панели:

| Страница       | Что показывает                                                                         |
| -------------- | -------------------------------------------------------------------------------------- |
| **Обзор**      | Карточку каждого хоста, движок выбранного хоста, использование диска и события         |
| **Контейнеры** | Все контейнеры, сгруппированные по стекам, с загрузкой CPU и памяти в реальном времени |
| **Образы**     | Локальные образы, что их использует, скачивание и очистку                              |
| **Тома**       | Тома и контейнеры, которые их используют                                               |
| **Сети**       | Сети, их подсети и подключённые контейнеры                                             |
| **Стеки**      | Проекты Compose, управляемые и внешние                                                 |
| **События**    | Всё, о чём сообщил движок с момента подключения Homeport                               |
| **Настройки**  | Тему, возможности этого компьютера и лицензии                                          |

Homeport обновляется по мере того, как движок сообщает об изменениях, так что кнопка обновления не нужна — запустите контейнер в терминале, и он сразу появится.

## 3. Запустите контейнер

<Steps>

1. Откройте **Контейнеры** и выберите **Запустить контейнер**.

2. Введите **Образ**, например `nginx:alpine`. Если на хосте его нет, Homeport сначала скачает его.

3. В разделе **Порты** выберите **Добавить порт** и сопоставьте порт хоста `8080` с портом контейнера `80`.

4. Выберите **Запустить**. Homeport откроет новый контейнер на вкладке **Журналы**.

</Steps>

На странице «Контейнеры» порт `8080:80/tcp` — это ссылка: выберите её, чтобы открыть сайт в браузере.

## 4. Добавьте другие хосты

Добавляйте сколько угодно хостов через **Добавить хост…** в переключателе хостов. «Обзор» показывает их все вместе; выберите карточку, чтобы переключиться на этот хост.

<Aside type="tip">
  Homeport запоминает выбранный хост и при запуске переподключается ко всем хостам.
</Aside>
