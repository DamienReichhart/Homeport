**Homeport** — настольное приложение для управления движками Docker где угодно — на этом компьютере или на удалённых машинах по SSH, TLS или TCP — и кластерами Kubernetes, до которых дотягивается ваш kubeconfig, в духе Docker Desktop. Он работает в Windows, macOS и Linux, бесплатен и распространяется с открытым исходным кодом по лицензии [GNU Affero General Public License версии 3](https://github.com/DamienReichhart/Homeport/blob/main/LICENSE).

Homeport сам не запускает контейнеры. Он подключается к уже имеющимся у вас движкам Docker, которые называются **хостами**, и даёт одно окно для всего, что на них есть: контейнеров, образов, томов, сетей и **стеков** Compose. Он также подключается к **кластерам** Kubernetes из вашего kubeconfig, чтобы просматривать то, что на них работает.

## Термины, которые мы используем

Homeport называет вещи точно, и документация следует ему:

- **Хост** — движок Docker, к которому подключается Homeport. Каждый контейнер, образ, том, сеть и стек принадлежит ровно одному хосту.
- **Кластер** — кластер Kubernetes, к которому подключается Homeport; он добавляется из контекста вашего kubeconfig.
- **Стек** — проект Compose, работающий на хосте. **Управляемый стек** — тот, чей compose-файл хранит Homeport; **связанный стек** хранит свои compose-файлы в папке на этом компьютере; **внешний стек** был развёрнут каким-то другим способом. Внешний стек можно **взять под управление**, чтобы управлять им.

Полный список — в [глоссарии](/docs/reference/glossary/).
