O **Homeport** é um aplicativo de desktop para gerenciar Docker Engines em qualquer lugar — o desta máquina ou Engines remotos via SSH, TLS ou TCP — e os clusters Kubernetes que o seu kubeconfig alcança, no espírito do Docker Desktop. Ele roda no Windows, macOS e Linux, é gratuito e é open source sob a [GNU Affero General Public License, version 3](https://github.com/DamienReichhart/Homeport/blob/main/LICENSE).

O Homeport não executa contêineres por conta própria. Ele se conecta aos Docker Engines que você já tem, chamados **hosts**, e oferece uma única janela para tudo o que há neles: contêineres, imagens, volumes, redes e **stacks** Compose. Ele também se conecta a **clusters** Kubernetes do seu kubeconfig, para navegar pelo que roda neles.

## As palavras que usamos

O Homeport dá nomes precisos às coisas, e a documentação faz o mesmo:

- Um **host** é um Docker Engine ao qual o Homeport se conecta. Cada contêiner, imagem, volume, rede e stack pertence a exatamente um host.
- Um **cluster** é um cluster Kubernetes ao qual o Homeport se conecta, adicionado a partir de um contexto do seu kubeconfig.
- Uma **stack** é um projeto Compose em execução em um host. Uma **stack gerenciada** é aquela cujo arquivo compose o Homeport guarda; uma **stack vinculada** mantém os seus arquivos compose em uma pasta deste computador; uma **stack externa** foi implantada de outra forma. Você pode **adotar** uma stack externa para gerenciá-la.

O [glossário](/docs/reference/glossary/) tem a lista completa.
