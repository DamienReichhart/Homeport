Homeport 提供适用于 Windows、macOS 和 Linux 的安装程序，每个系统都有 x64 和 ARM 版本。可以从[下载页面](/download/)获取（它会为你的系统指出合适的文件），也可以从[最新的 GitHub 发布](https://github.com/DamienReichhart/Homeport/releases/latest)获取。在 Linux 上，Homeport 软件包仓库只需一条命令即可安装。

每种安装方式都会保持最新：在 Windows、macOS 上以及使用 AppImage 时，Homeport 会自行更新；Linux 软件包则随系统其余部分一起更新。参见[更新](/docs/reference/updating/)。

<Aside>
  Homeport 用于管理 Docker Engine，但并不自带 Docker Engine。如果想在本机上运行容器，还需安装 Docker
  Engine、Docker Desktop、Colima、OrbStack、Rancher Desktop 或 Podman；也可以改为将 Homeport
  连接到远程服务器。参见[系统要求](/docs/requirements/)。
</Aside>

## Windows

| 文件                                         | 用途                                           |
| -------------------------------------------- | ---------------------------------------------- |
| `Homeport-<version>-windows-x64-setup.exe`   | 大多数 PC。为当前用户安装。                    |
| `Homeport-<version>-windows-arm64-setup.exe` | Windows on ARM（Snapdragon 及其他 ARM64 PC）。 |
| `Homeport-<version>-windows-x64.msi`         | x64 上的托管安装和静默安装。                   |

<Steps>

1. 下载适合你 PC 的安装程序并打开。

2. Windows SmartScreen 可能会提示 **Windows 已保护你的电脑**（Windows protected your PC），因为安装程序目前尚未使用付费证书签名。选择**更多信息**（More info），然后选择**仍要运行**（Run anyway）。

3. 按照安装程序的提示操作。Homeport 会被添加到“开始”菜单。

</Steps>

使用 MSI 软件包进行静默安装：

```powershell
msiexec /i Homeport-<version>-windows-x64.msi /quiet
```

## macOS

| 文件                                 | 用途                                     |
| ------------------------------------ | ---------------------------------------- |
| `Homeport-<version>-macos-arm64.dmg` | 搭载 Apple 芯片的 Mac（M1 及更新机型）。 |
| `Homeport-<version>-macos-x64.dmg`   | 搭载 Intel 处理器的 Mac。                |

不确定你的 Mac 是哪一种？打开苹果菜单 → **关于本机**（About This Mac）：有**芯片**（Chip）一行表示 Apple 芯片，有写着 Intel 的**处理器**（Processor）一行表示 Intel。

<Steps>

1. 打开 `.dmg`，将 **Homeport** 拖入**应用程序**（Applications）。

2. 从“应用程序”或启动台打开 Homeport。

3. Homeport 目前尚未经过 Apple 公证，因此 macOS 可能会提示**无法打开**或**无法检查其是否包含恶意软件**。选择**完成**（或**好**），打开**系统设置 → 隐私与安全性**（System Settings → Privacy & Security），滚动到“安全性”，然后选择 Homeport 旁边的**仍要打开**（Open Anyway）。确认后，macOS 会记住你的选择。

</Steps>

<Aside type="tip" title="通过终端">
  也可以清除 macOS 为下载的应用添加的隔离标记：

```sh
xattr -dr com.apple.quarantine /Applications/Homeport.app
```

</Aside>

## Linux

Linux 版 Homeport 需要 glibc 2.35 或更高版本（Ubuntu 22.04、Debian 12、Fedora 36 或更新的系统），支持 x64 或 ARM64。

以下命令会设置 Homeport 软件包仓库并安装 Homeport，之后 `apt`、`dnf` 或 `zypper` 会随系统其余部分一起保持它为最新：

该脚本适用于 Debian、Ubuntu 及其衍生版（`apt`），Fedora、RHEL 及其相关发行版（`dnf`），以及 openSUSE（`zypper`）。它会在请求 `sudo` 之前说明将要做什么，然后：

2. 添加 Homeport 仓库，
3. 安装 `homeport` 软件包；如果已安装，则更新它。

重复运行不会造成任何问题。你可以先[阅读脚本](https://github.com/DamienReichhart/Homeport/blob/main/packaging/linux/install.sh)，或按照下面的手动设置操作：效果完全相同。

### 软件包文件

也可以下载适合你的处理器的 `.deb` 或 `.rpm`（Intel 和 AMD 用 `x64`，ARM 用 `arm64`）并直接安装：

<Tabs syncKey="linux-format">
<TabItem label="Debian, Ubuntu">

```sh
sudo apt install ./Homeport-<version>-linux-x64.deb
```

</TabItem>
<TabItem label="Fedora, RHEL">

```sh
sudo dnf install ./Homeport-<version>-linux-x64.rpm
```

</TabItem>
<TabItem label="openSUSE">

```sh
sudo zypper install ./Homeport-<version>-linux-x64.rpm
```

</TabItem>
</Tabs>

首次安装这些软件包之一时，它也会添加 Homeport 仓库，因此你会以与快速安装相同的方式获得更新。如果不想这样，请删除仓库文件（`/etc/apt/sources.list.d/homeport.sources`、`/etc/yum.repos.d/homeport.repo` 或 `/etc/zypp/repos.d/homeport.repo`）：之后的软件包更新不会再把它加回来。

### AppImage

AppImage 无需安装即可在大多数发行版上运行，并可在 Homeport 内部自行更新。将其设为可执行并运行：

```sh
chmod +x Homeport-<version>-linux-x64.AppImage
./Homeport-<version>-linux-x64.AppImage
```

每次运行时，它都会将 Homeport 添加到你的应用程序菜单。如果无法启动并提到 FUSE，请安装 `libfuse2`（Ubuntu 24.04 及更高版本为 `libfuse2t64`）。

`.deb` 和 `.rpm` 软件包会将 Homeport 添加到应用程序菜单，并将其许可证声明安装到 `/usr/share/doc/homeport/` 或 `/usr/share/licenses/homeport/`。

<Aside type="caution" title="在本机上使用 Docker？">
  要在不使用 root 的情况下访问本地 Docker 套接字，你的用户必须属于 `docker` 组：

```sh
sudo usermod -aG docker $USER
```

注销并重新登录后才会生效。否则，本地主机会显示为**无法访问**，并提示 _Permission denied_。

</Aside>
