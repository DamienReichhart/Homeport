本指南带你从全新安装开始，到在第一台主机上运行一个容器。

## 1. 添加主机

首次打开 Homeport 时，它会显示**欢迎使用 Homeport**。

如果本机上正在运行 Docker Engine，它会出现在**在本机上找到**下方，并显示版本，例如 `Docker Desktop · Engine 27.3.1`。选择它旁边的**添加**即可完成连接，然后直接跳到[第 2 步](#2-look-around)。

如果要连接远程引擎，请选择**添加其他主机**：

<Steps>

1. 选择连接方式：**SSH**、**TLS**、**TCP** 或**本地套接字**。连接服务器通常选择 SSH。

2. 为主机取一个你能认出的**名称**，例如 `production`。

3. 填写连接详情。对于 SSH，需要填写**服务器**、**端口**、**用户**；如果 Docker 不在默认位置，还需填写**远程套接字路径**。

4. 选择**添加主机**。Homeport 会打开该主机的页面并开始连接。

</Steps>

  alt="选中了 SSH 的“添加主机”页面。"
  caption="添加 SSH 主机。Homeport 会专门为它创建一个密钥。"

SSH 主机首次连接时还需要做两件事。[SSH 主机](/docs/hosts/ssh/)会逐步说明：

- **信任服务器的密钥。** Homeport 会显示服务器的指纹；核对后选择**信任此密钥**。
- **授权 Homeport 的密钥。** 复制**在服务器上授权 Homeport** 下方的命令，在服务器上运行，然后选择**重新连接**。

状态变为**已连接**后，就完成了。

## 2. 四处看看

侧边栏中每种资源都有一个页面，它们都显示侧边栏顶部**主机切换器**中选中的主机：

| 页面     | 显示内容                                             |
| -------- | ---------------------------------------------------- |
| **概览** | 每台主机一张卡片，以及所选主机的引擎、磁盘用量和事件 |
| **容器** | 所有容器，按堆栈分组，并显示实时 CPU 和内存          |
| **镜像** | 本地镜像、使用它们的对象，以及拉取和清理             |
| **卷**   | 卷以及使用它们的容器                                 |
| **网络** | 网络、其子网和已连接的容器                           |
| **堆栈** | Compose 项目，包括托管堆栈和外部堆栈                 |
| **事件** | 自 Homeport 连接以来引擎报告的内容                   |
| **设置** | 主题、本机支持的功能，以及许可证                     |

Homeport 会在引擎报告变化时自动刷新，因此你永远不需要刷新按钮：在终端中启动一个容器，它会立即出现。

## 3. 运行容器

<Steps>

1. 打开**容器**，选择**运行容器**。

2. 输入**镜像**，例如 `nginx:alpine`。如果主机上没有该镜像，Homeport 会先拉取它。

3. 在**端口**下选择**添加端口**，将主机端口 `8080` 映射到容器端口 `80`。

4. 选择**运行**。Homeport 会在**日志**标签页中打开新容器。

</Steps>

回到“容器”页面，端口 `8080:80/tcp` 是一个链接：选择它即可在浏览器中打开该网站。

## 4. 添加更多主机

使用主机切换器中的**添加主机…**，想添加多少台主机都可以。“概览”页面会把它们全部显示在一起；选择一张卡片即可切换到该主机。

<Aside type="tip">Homeport 会记住你选中的主机，并在启动时重新连接所有主机。</Aside>
