Homeport 的目标是在其所有[语言](/docs/guides/settings/#appearance)中，都能仅用键盘、配合屏幕阅读器以及在减弱动态效果的情况下使用。本页说明哪些功能可用、哪些尚不可用，以及当某些东西妨碍你使用时如何告诉我们。

## 导航

Homeport 中的一切都可以用 <kbd>Tab</kbd> 和 <kbd>Shift</kbd> <kbd>Tab</kbd> 访问，并用 <kbd>Enter</kbd> 或 <kbd>Space</kbd> 操作。一个可见的焦点环会显示焦点所在位置。

- **侧边栏**列出每个页面；每个页面都是一个链接。<kbd>Mod</kbd> <kbd>1</kbd> 到 <kbd>9</kbd> 按顺序打开它们，[命令面板](/docs/guides/keyboard/#command-palette)（<kbd>Mod</kbd> <kbd>K</kbd>）可以通过输入访问每个页面、主机和操作。
- **列表**（容器、镜像、卷、网络、堆栈、主机、Pod…）：每一行的名称都是一个按钮或链接。用 <kbd>Tab</kbd> 移到它上面并按 <kbd>Enter</kbd> 即可打开该项，效果与点击该行相同。复选框和该行的菜单分别位于它之前和之后。
- **排序**：可排序列的标题是一个按钮。按 <kbd>Enter</kbd> 或 <kbd>Space</kbd> 按该列排序，再按一次则反向排序；屏幕阅读器会播报排序顺序。
- **容器列表中的堆栈**通过其名称前的按钮展开和折叠，该按钮会说明当前是否已展开。
- **对话框**打开时获得焦点，打开期间焦点保持在其内部，关闭时将焦点交还给打开它的元素。<kbd>Esc</kbd> 关闭对话框而不执行任何操作。
- **菜单、选择框和标签页**使用方向键、<kbd>Home</kbd> 和 <kbd>End</kbd> 移动；<kbd>Enter</kbd> 选择，<kbd>Esc</kbd> 关闭。
- **快捷键**：在任意页面上按 <kbd>?</kbd> 会列出该页面可用的快捷键；参见[键盘](/docs/guides/keyboard/)。

## 终端、日志和编辑器

容器的**终端**和日志查看器在获得焦点时会接收所有按键，因此其中的程序也能收到 <kbd>Tab</kbd>、<kbd>Esc</kbd> 和 <kbd>Ctrl</kbd> 组合键。可以用鼠标离开它们，或使用屏幕阅读器自己的命令移动焦点。

compose、YAML、job 和单元编辑器都是 CodeMirror 编辑器，并为屏幕阅读器提供了名称。在编辑器中，<kbd>Tab</kbd> 用于缩进；先按 <kbd>Esc</kbd> 再按 <kbd>Tab</kbd> 即可将焦点移出编辑器。

## 减弱动态效果

当操作系统要求减弱动态效果时（macOS 上的**减弱动态效果**，Windows 上关闭**动画效果**，GNOME 和 KDE 上的**减少动画**），Homeport 只使用淡入淡出：对话框、菜单、选择框和工具提示不会缩放或滑动，没有任何东西会闪烁，按钮按下时不会移动，终端的光标也会停止闪烁。加载指示器仍会旋转，但更慢，因为它们表示工作正在进行。该设置的变化会实时生效，无需重启。

## 屏幕阅读器

每次更改时，每个页面和主要对话框都会用 [axe](https://github.com/dequelabs/axe-core) 检查：按钮、字段和区域都有名称，标题和地标的顺序正确，并且没有误用 ARIA。Homeport 会设置页面的语言，因此屏幕阅读器会用对应语言的语音朗读每种语言，阿拉伯语会从右到左显示。

Homeport 的窗口是一个 Web 视图：Linux 上为 WebKitGTK，macOS 上为 WKWebView，Windows 上为 WebView2。目前正在分别使用 Orca、VoiceOver 和 NVDA 进行实际审查（[#184](https://github.com/DamienReichhart/Homeport/issues/184)）；在完成之前，请将屏幕阅读器体验视为仅经过工具测试。

### 已知局限

- **终端和日志**：屏幕阅读器目前还无法朗读容器终端和日志查看器中的文本。请复制输出，或在终端中用 `docker logs` 打开日志。
- **实时列表**：列表会在引擎报告变化时原地刷新，但不会播报每一次变化。toast 通知会播报你执行的操作。
- **图表**会绘制其数值；每个图表的最新值也以文本形式出现在图表标题中。

## 对比度

在浅色和深色主题中，文本都满足 WCAG 2.2 AA（4.5:1），字段边框、焦点环和状态形状也同样满足（3:1）。状态从不只依赖颜色：每种状态都有自己的形状。具体比率列在项目的品牌指南中。

## 报告障碍

如果有什么阻碍了你通过键盘、屏幕阅读器、放大镜或其他辅助技术使用 Homeport，请[创建 issue](https://github.com/DamienReichhart/Homeport/issues/new?labels=accessibility)，并加上 `accessibility` 标签。请说明：

- 你想做什么，以及在哪里（页面、对话框、主机类型）；
- 你的操作系统及其版本，以及辅助技术及其版本；
- 你听到或看到了什么，以及你预期的是什么。

障碍会被当作 bug 处理，而不是功能请求。
