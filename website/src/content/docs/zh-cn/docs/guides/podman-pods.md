title: Podman Pod
description: 列出、启动、停止和删除 Podman Pod，创建带有发布端口的 Pod，并在其中运行容器。
---

**Pod** 是 Podman 组合容器的方式：其中的容器共享同一网络（以及主机名和 IPC），因此可以通过 `localhost` 互相访问，并且一起启动和停止。每个 Pod 都有一个 **infra 容器**，它持有共享的内容以及 Pod 发布的端口。对于引擎为 Podman 的主机，Homeport 会通过 Podman 自己的 API，在主机已使用的套接字上显示 Pod；主机上不会安装任何东西。

**Pod** 页面只在选择了 Podman 主机时出现在侧边栏中。在其他 Docker 兼容引擎上没有这个页面，指向它的链接会说明原因。Homeport 如何识别 Podman，请参阅[引擎类型](/docs/hosts/#engine-kinds)。

## Pod 页面

| 列           | 显示内容                                                                                   |
| ------------ | ------------------------------------------------------------------------------------------ |
| **名称**     | Pod 的名称，并以圆点表示其状态。                                                           |
| **状态**     | **运行中**、**部分运行**（部分容器已停止）、**已暂停**、**已停止**、**已创建**或**失败**。 |
| **容器**     | 它自身的容器中有多少个正在运行，不计 infra 容器。                                          |
| **网络**     | Pod 所在的网络。                                                                           |
| **创建时间** | 创建的时间。                                                                               |

每一行都有与其状态相符的操作（已停止的 Pod 为**启动**，正在运行的为**停止**）以及**删除**。选择一个 Pod 即可打开其页面。无论容器是从 Homeport 还是从终端启动和停止，列表都会随 Pod 中容器的启停自动更新。

在**容器**页面上，在 Pod 中运行的容器会在自己的名称旁显示 Pod 的名称；选择该名称即可打开 Pod。

## Pod 的页面

页头有**运行容器**以及 Pod 的操作：**启动**、**停止**、**重启**、**暂停**、**恢复**和**删除**，视其状态而定。每个操作都会同时作用于 Pod 的所有容器，与 `podman pod start` 等命令相同。

- **容器**列出 Pod 的容器，infra 容器排在最后。选择一个即可打开其容器页面，包含日志、终端和文件。
- **设置**显示 Pod 发布的端口、其容器共享的命名空间、它的网络、主机名和标签，以及创建它时使用的 `podman pod create` 命令（如果 Podman 保留了该命令）。

## 删除 Pod

**删除**会先询问，并说明有多少个容器会随 Pod 一起删除。正在运行的 Pod 会先被停止：按钮显示为**停止并删除**。Pod 的卷会保留。

## 创建 Pod

**新建 Pod**（或在 Pod 页面按 `n`，或在命令面板中选择**新建 Pod**）会要求填写：

- **名称**：字母、数字、`_`、`.` 和 `-`，以字母或数字开头；
- 要发布的**端口**，主机端口对应容器端口，与“运行”对话框相同。主机端口留空则由 Podman 选择一个空闲端口；
- **标签**，每行一个 `key=value`。

端口属于 Pod：它们发布在 Pod 的 infra 容器上，并到达 Pod 中监听该端口的任意容器。新 Pod 的页面会打开，可以直接在其中运行容器。在你运行容器之前，Pod 没有自己的容器；Podman 会随第一个容器启动它。

## 在 Pod 中运行容器

在 Podman 主机上，**运行**对话框有一个 **Pod** 字段，Pod 的**运行容器**按钮会打开已选中该 Pod 的对话框。Pod 中的容器：

- 共享 Pod 的网络，因此不能发布端口或加入其他网络：选择 Pod 后，对话框会隐藏这些字段；
- 使用 Pod 的主机名和 DNS 设置，因此 Homeport 会拒绝容器自己的设置；
- 保留“运行”对话框提供的其他所有选项：命令、环境变量、挂载、重启策略、限制、capabilities、设备、健康检查和日志。

“复制”和“编辑”绝不会把容器移入 Pod：Podman 无法将已有容器移入 Pod。

## Homeport 需要什么

Pod 适用于 Podman 4.0 及更高版本，支持所有连接方式（本地套接字、SSH、TLS 或 TCP），因为它们与其他所有内容走同一个套接字。
