**实例**是 [Incus 主机](/docs/hosts/incus/)运行的东西：**系统容器**，它与主机共享内核并启动一个完整的 Linux 发行版；或者**虚拟机**，它有自己的内核。这里的每个页面都显示在主机切换器下选择的项目。

## 实例页面

**实例**列出项目中的实例，包括它们的类型、状态、镜像、全局地址（IPv4 在前）、内存和存在时长。可以按名称筛选，或只显示容器或虚拟机。

| 操作         | Incus 执行的操作                                                                     |
| ------------ | ------------------------------------------------------------------------------------ |
| **启动**     | 启动它。                                                                             |
| **停止**     | 请求其系统关机，并给它 30 秒；未能关机的会被报告，并提供**强制停止**作为解决办法。   |
| **强制停止** | 立即切断它，就像拔掉电源。                                                           |
| **重启**     | 正常关机后再次启动。                                                                 |
| **冻结**     | 暂停其中的所有进程；**解冻**会恢复它们。                                             |
| **删除**     | 先询问，并列出将随之删除的快照。正在运行的实例只有在勾选**请先停止它**后才会被删除。 |

无论是谁做的更改，列表都会在片刻内根据 Incus 的事件刷新。

实例的页面包含**概览**（地址、CPU 时间、内存、进程、快照以及它的配置文件，每个配置文件都链接到其页面）、**配置**和**设备**（其配置文件设置的内容标记为**来自配置文件**），以及在**原始数据**下 Incus 自己对它的描述。

## 创建实例

**新建实例**（或 <kbd>n</kbd>）从镜像创建实例：

- **来自镜像服务器**：默认为公共的 `https://images.linuxcontainers.org`，也可以是其他 simplestreams 服务器。Homeport 会列出它为主机架构发布的镜像（容器或虚拟机），可按系统、版本或别名搜索；也可以输入别名，例如 `debian/12` 或 `ubuntu/24.04/cloud`。Incus 会下载镜像，与 `incus launch images:debian/12` 相同。
- **来自此主机的镜像**：主机已保存的镜像。

选择它的**配置文件**（按顺序：后面的覆盖前面的），并可选择设置 **CPU**、**内存**（`2GiB`）和**根磁盘**大小（`20GiB`，位于其配置文件的根磁盘所在的存储池中）。**创建后启动**默认开启。对话框会以 Incus 自己的措辞跟踪下载和解包过程，然后打开新实例。

名称已被使用、服务器上没有该镜像、存储池已满，或在不支持硬件虚拟化（没有 `/dev/kvm`）的主机上创建虚拟机时，都会说明情况以及该怎么做。

## 控制台和终端

**控制台**显示实例到目前为止在其文本控制台上输出的内容，然后连接到控制台：登录提示，或正在进行的启动过程，与 `incus console` 显示的一样。它也适用于虚拟机，以及实例的网络或 SSH 出现故障的情况。离开该标签页或选择**重新连接**只会断开连接。

**Exec** 会在正在运行的实例中打开一个 shell（有 bash 时用 bash，否则用 sh），或运行你给出的命令，并以你选择的数字用户身份在你选择的文件夹中运行；**打开**会用你输入的内容启动一个新会话。关闭标签页会挂断命令，因此从中启动的任何东西都不会继续运行。在虚拟机中，exec 需要 `incus-agent`，Incus 自己的镜像包含它并在开机时启动；在它运行之前，Homeport 会说明这一点，此时可以通过“控制台”标签页进入。

## 快照

**快照**列出实例的快照，以及每个快照的创建时间、过期时间和是否包含运行状态。

- **创建快照**为快照命名（或让 Incus 将其命名为 `snap0`、`snap1`…），并将其保留到删除为止，或保留一天、一周或 30 天。当实例正在运行且其 `migration.stateful` 设置允许时，快照可以包含其内存，这样恢复时会从原处继续运行。
- **恢复**会将实例还原到创建快照时的状态。此后的所有更改都会丢失，正在运行的实例会重启，因此 Homeport 会先询问。
- **删除**会在询问后删除快照；实例保持原样。

## 镜像

**镜像**列出项目保存的镜像，包括它们的别名、描述、类型、架构、大小和存在时长。Incus 为创建实例而下载的镜像标记为**已缓存**：一段时间没有被使用后，Incus 会删除它们。

- **获取镜像**会提前从镜像服务器下载一个镜像，选择方式与新建实例相同。**从服务器保持更新**让 Incus 从服务器刷新它；**在此处使用相同的别名**让新实例可以按名称使用它。
- **刷新**会从镜像的来源获取更新的构建。
- 标签按钮用于添加别名；别名上的叉号用于删除它。
- **删除**会删除镜像。从它创建的实例会继续工作：每个实例都有自己的副本。

## 配置文件

**配置文件**列出项目的配置文件，以及每个配置文件设置了多少个键和设备，以及使用它的实例。配置文件的页面以 YAML 形式编辑其描述、配置和设备，与 `incus profile edit` 相同，并链接到使用它的实例。**保存**会将更改应用到这些实例，与 Incus 的做法相同。如果在页面加载配置文件之后有人更改了它，保存会被拒绝，而不是覆盖他们的更改：请**重新加载**，然后重新进行更改。

**新建配置文件**会创建一个空的配置文件并打开它。`default` 以及实例正在使用的配置文件无法删除。

## 存储

**存储**显示每个存储池及其驱动和使用量，以及所选存储池中属于该项目的卷：实例和镜像自己的卷，以及自定义卷，包括它们的内容类型、大小和使用者。

**新建卷**会创建一个自定义卷（文件系统或块设备），大小可以指定或使用存储池的默认值，用于挂接到实例上，存放比实例存在得更久的数据（`incus storage volume attach`）。自定义卷在没有任何东西使用时可以删除。存储池本身使用 `incus storage create` 创建。

## 网络

**网络**列出项目可见的网络，托管网络（由 Incus 创建）排在前面，包括它们的 IPv4 和 IPv6 设置、NAT 和使用者。网络的页面显示它在主机上的地址、MTU 和 MAC 地址、使用它的实例和配置文件，对于托管网络还显示 DHCP 租约，与 `incus network list-leases` 相同。

**新建网桥**会创建一个托管网桥。它的 IPv4 和 IPv6 为 `auto`（一个空闲子网）、`none`，或网桥自己的地址及其前缀，例如 `10.0.5.1/24`；**NAT** 会对出站 IPv4 流量进行地址伪装。正在使用的网络或本机自身的接口无法在这里删除。
