Homeport 可以完全用键盘操作。按 <kbd>Mod</kbd> <kbd>K</kbd> 打开[命令面板](#命令面板)，在任意页面按 <kbd>?</kbd> 可查看该页面可用的所有快捷键。

下文中的 **Mod** 在 macOS 上指 <kbd>⌘</kbd>，在 Windows 和 Linux 上指 <kbd>Ctrl</kbd>；在 macOS 上，<kbd>Alt</kbd> 即 <kbd>⌥</kbd>。

## 命令面板

在任意页面按 <kbd>Mod</kbd> <kbd>K</kbd> 都会打开命令面板。输入想要的内容，用 <kbd>↑</kbd> 和 <kbd>↓</kbd> 移动，然后按 <kbd>Enter</kbd>；<kbd>Esc</kbd> 会关闭它并回到原来的位置。它列出：

- **转到**：侧边栏中的每个页面。输入 `vol` 并按 <kbd>Enter</kbd> 即可打开“卷”。
- **主机**：每个主机及其状态。输入主机名称的一部分即可切换到该主机。
- **操作**：**运行容器**、**拉取镜像**、**新建堆栈**、**清理所选主机**、**添加主机**、**管理主机**、**检查更新**和**显示键盘快捷键**。
- **设置**：**主题：浅色**、**主题：深色**和**主题：跟随系统**。

需要主机的操作（运行容器、拉取、新建堆栈、清理）只在所选主机已连接时列出。

### 搜索所有主机

输入两个或更多字符后，命令面板还会搜索每个已连接主机的**容器**、**堆栈**、**镜像**、**卷**和**网络**。“`postgres` 在哪里运行？”无需切换主机就能得到答案。它匹配名称、短 ID，对容器还匹配其镜像和堆栈；以所输入内容开头的名称排在前面。

- 结果按类型分组，每种类型显示五个，直到选择**显示全部**。每个结果都会显示其主机，容器和堆栈还会显示是否在运行：_prod-server · 运行中_。
- 选择一个结果会切换到它的主机并打开它：容器或堆栈的页面，或者以它为搜索词的“镜像”“卷”或“网络”页面。
- 未连接的主机会被跳过，命令面板会显示数量：_2 个主机未搜索（未连接）_。

Homeport 只在你输入两个字符后才加载这些列表，之后通过每个主机的实时事件保持更新。日志、文件和 compose 定义不会被搜索。每个项目都会显示其快捷键（如果有）。未输入任何内容时，最近使用过的项目排在前面，位于**最近使用**下，直到 Homeport 退出。

## 快捷键

### 全局

| 按键                                       | 作用                                            |
| ------------------------------------------ | ----------------------------------------------- |
| <kbd>?</kbd>                               | 显示键盘快捷键                                  |
| <kbd>Mod</kbd> <kbd>1</kbd> … <kbd>9</kbd> | 按顺序打开侧边栏中的页面：概览、容器、镜像…     |
| <kbd>Mod</kbd> <kbd>,</kbd>                | 打开设置                                        |
| <kbd>Alt</kbd> <kbd>↑</kbd> / <kbd>↓</kbd> | 按“主机”页面中的顺序选择上一个或下一个主机      |
| <kbd>Mod</kbd> <kbd>R</kbd>                | 刷新所选主机的列表：容器、镜像、卷、网络、堆栈… |

将鼠标悬停在侧边栏中的页面上即可查看其按键。

### 页面内

| 按键         | 作用                                                                                             |
| ------------ | ------------------------------------------------------------------------------------------------ |
| <kbd>/</kbd> | 聚焦页面的搜索框。在空白搜索框中按 <kbd>Esc</kbd> 会离开它。                                     |
| <kbd>N</kbd> | 启动页面的主要操作：**运行容器**、**拉取**、**创建卷**、**创建网络**、**新建堆栈**或**添加主机** |

将鼠标悬停在页面主要操作的按钮上时，会显示 <kbd>N</kbd>。

### 输入时

在输入框、堆栈编辑器或对话框中输入时，单键快捷键（<kbd>N</kbd>、<kbd>/</kbd>、<kbd>?</kbd> 和 <kbd>Alt</kbd> 方向键）绝不会触发，而是输入对应字符。带 <kbd>Mod</kbd> 的快捷键在这些地方同样有效。在容器的**终端**中，每个按键都会发送到容器，不会触发任何快捷键。
