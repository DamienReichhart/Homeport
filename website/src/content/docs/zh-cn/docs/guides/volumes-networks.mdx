## 卷

**卷**页面列出所选主机的卷，以及其中有多少个未被使用。

<DocScreenshot name="volumes" alt="卷页面，显示每个卷的堆栈、驱动以及使用它的容器。" />

| 列           | 显示内容                                              |
| ------------ | ----------------------------------------------------- |
| **名称**     | 卷的名称；匿名卷显示为一个长 ID。                     |
| **堆栈**     | 创建它的堆栈（如果有）。                              |
| **驱动**     | 通常为 `local`。                                      |
| **大小**     | 其数据占用的磁盘空间，以 `docker system df -v` 为准。 |
| **使用者**   | 挂载它的容器，或**未使用**。                          |
| **创建时间** | 创建的时间。                                          |

只要有任何容器挂载了某个卷，无论容器正在运行还是已停止，该卷都算作被使用。选择一个卷即可查看其大小、使用它的容器以及完整详细信息，包括其数据在主机上的位置（`Mountpoint`）。

### 大小

引擎需要测量每个卷才能给出大小，在数据很多的主机上这可能需要几秒钟，因此列表会立即显示，**大小**列随后才填入。按**大小**排序即可找出占满磁盘的卷。创建或删除卷时，以及选择**刷新大小**时，会重新测量大小，而不是在容器每次写入时都测量，因此大小可能略有滞后。

只有 `local` 驱动的卷才有大小；其他驱动（NFS、云存储插件）显示 **—**。

### 浏览卷的文件

卷所在行上的文件夹按钮会打开它的文件：打开文件夹，通过列表上方的路径返回上级，并下载文件，或将文件夹下载为 `.tar` 归档。路径从卷的根目录（`/`）开始。

浏览是只读的。在这里做的任何操作都不会更改卷，即使有容器正在使用它。

#### 辅助容器

引擎 API 无法读取卷，因此 Homeport 使用一个短期存在的**辅助容器**来打开它：一个没有网络、文件系统只读的 `busybox:1.37` 容器，它以只读方式挂载卷。关闭浏览器或退出时，Homeport 会立即删除它。如果 Homeport 无法删除（它崩溃了，或主机断开了），辅助容器会停止并在一小时内被引擎删除，Homeport 会在本机下次连接到该主机时删除剩余部分。辅助容器从不显示在“容器”列表、卷的**使用者**或“事件”页面中。

如果主机上没有 `busybox:1.37`（约 2 MB），Homeport 会说明这一点，只有在你选择**拉取 busybox:1.37** 后才会使用你的[镜像仓库登录](/docs/guides/settings/#registries)拉取它。用完后，除非有其他东西在使用该镜像，否则 Homeport 会再次删除它。无法访问互联网的主机无法拉取它；请自行将它放到主机上：

```sh
docker pull busybox:1.37
```

或者，在已有该镜像的机器上运行 `docker save busybox:1.37 -o busybox.tar`，将文件复制过去，然后在主机上运行 `docker load -i busybox.tar`。

<Aside>运行 Windows 容器的引擎无法运行辅助容器，因此无法打开它们的卷。</Aside>

### 备份和恢复

卷所在行 **⋯** 菜单中的**备份到文件…**会将其内容保存到本机上的 `.tar` 文件中。归档包含卷的文件及其所有者和权限，路径相对于卷的根目录，与 `tar -C <volume> -cf backup.tar .` 生成的相同，因此不用 Homeport 也可以打开或恢复它。

**从文件恢复**用于恢复备份：

- 从页面顶部恢复到**新卷**（除非你更改，否则以文件名命名），或你选择的**现有卷**。
- 从卷的 **⋯** 菜单恢复到该卷。

如果现有卷中已有文件，Homeport 会先询问，然后再删除它们并放入备份中的文件。不是 tar 归档的文件会在任何更改发生前被拒绝。

两者都会显示进度，并且可以取消。取消的备份不会留下文件；取消的恢复可能会使卷处于部分写入的状态，因此在使用前请重新恢复一次。

#### 使用该卷的容器

对正在运行的容器写入的卷（例如数据库）进行备份，结果可能不一致。Homeport 会列出使用该卷的正在运行的容器，你可以选择**仍然备份**，或在备份期间停止它们。恢复总是会先停止它们。无论哪种方式，Homeport 都会在之后重新启动它们。

备份和恢复使用与浏览相同的[辅助容器](#the-helper-container)，备份时以只读方式挂载卷。归档通过主机的连接传输，从不整体保存在内存中，因此大型卷和远程主机也没有问题。除了正在恢复的卷之外，不会在主机上写入任何东西。

### 克隆卷

卷所在行 **⋯** 菜单中的**克隆…**会将其复制到同一主机上的一个新卷中，例如在真实数据的副本上尝试迁移或新版本的镜像。副本默认命名为 `<name>-copy`，你也可以更改，创建后会在列表中被选中。

它会保留文件的所有者和权限，以及源卷的驱动、驱动选项和标签（Compose 的标签除外，因此副本不属于任何堆栈）。源卷在[辅助容器](#the-helper-container)中以只读方式挂载，从不会被更改。与备份一样，Homeport 会列出使用源卷的正在运行的容器；你可以仍然复制，或在复制期间停止它们。

如果复制失败（例如磁盘已满），Homeport 会删除不完整的副本并说明情况，错误信息位于**详细信息**中。要将卷复制到另一个主机，请[备份它](#backing-up-and-restoring)，然后在那里恢复该文件。

### 创建卷

**创建卷**会要求填写**名称**和可选的**驱动**（留空时为 `local`）。

### 删除卷

<Aside type="danger">删除卷会永久删除其中的数据。</Aside>

每一行上的删除按钮会要求确认，并列出仍挂载该卷的容器。引擎会拒绝删除任何容器（即使是已停止的容器）正在使用的卷，请先删除这些容器。

**清理**可一次删除多个卷：

- **未使用的匿名卷**：没有容器使用的未命名卷。
- **所有未使用的卷**：没有容器使用的所有卷，包括已命名的卷。

## 网络

**网络**页面列出所选主机的网络，内置的 `bridge`、`host` 和 `none` 排在前面。

<DocScreenshot name="networks" alt="网络页面，显示内置网络和堆栈网络、它们的子网以及容器数量。" />

| 列       | 显示内容                                       |
| -------- | ---------------------------------------------- |
| **名称** | 适用时带有**内置**或**内部**标记。             |
| **堆栈** | 创建它的堆栈（如果有）。                       |
| **驱动** | `bridge`、`overlay`、`macvlan`…                |
| **子网** | 其 IP 范围。                                   |
| **容器** | 有多少个容器连接到它，无论正在运行还是已停止。 |

### 连接容器

选择一个网络即可查看连接到它的容器。在你创建的网络上：

- **断开连接**会使容器脱离网络。
- **连接容器…**会列出尚未连接的容器；选择一个，然后选择**连接**。

内置网络无法在这里更改。

### 创建网络

**创建网络**需要填写**名称**、**驱动**（留空时为 `bridge`），以及可选的**子网**和**网关**，留空则由引擎选择。还有两个开关：

- **内部**：网络上的容器无法访问外部网络。
- **可连接**：独立容器可以加入 `overlay` 网络。

### 删除网络

内置网络无法删除。对于其他网络，确认对话框会说明仍有多少个容器连接在上面；引擎会拒绝删除有正在运行的容器的网络。按名称引用已删除网络的容器在该网络重新存在之前将无法启动。

**清理**会删除没有任何容器连接的所有自定义网络。
