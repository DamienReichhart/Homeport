## Updating

How Homeport updates depends on how you installed it.

### Windows, macOS and the AppImage

Homeport checks for a new version when it starts and every 6 hours. When one is out, a bar at the top of the window says so: choose **What's new** to read the [changelog](/changelog/), or **Install and restart**. Homeport downloads the update, checks its signature, installs it and opens again. Nothing is installed until you choose to, and your Hosts, Stacks and settings are kept.

You can also check now from **Settings → Updates → Check now**.

### Linux packages

The `.deb` and `.rpm` packages, whether installed with the [quick install](/docs/installation/#quick-install), the [manual setup](/docs/installation/#manual-setup) or a downloaded file, update from the Homeport package repository with the rest of your system: your usual software updates include Homeport. To update only Homeport:

<Tabs syncKey="linux-format">
  {MANUAL_SETUP.map((setup) => (
    <TabItem label={setup.label}>
      <Code code={UPDATE_COMMANDS[setup.id]} lang="sh" />
    </TabItem>
  ))}
</Tabs>

Homeport tells you when a new version is out and shows the command for your system, but leaves installing it to your package manager.

If you removed the Homeport repository, your package manager can't see new versions. Set it up again with the [quick install](/docs/installation/#quick-install), or download the new package and install it over the old one.

### Turning update checks off

Turn off **Settings → Updates → Check for updates automatically**. **Check now** still works. A check downloads one small file from this website and sends nothing about you or your Hosts. See [security and your data](/docs/reference/security/#what-homeport-connects-to).

### Updating from 0.2.0 or earlier

Versions before 0.3.0 don't update themselves, and their Linux packages don't add the repository. Install 0.3.0 or later once, the same way you installed Homeport: from the [download page](/download/), or on Linux with the [quick install](/docs/installation/#quick-install). After that, updates come by themselves.

To hear about new versions anyway, watch the repository on GitHub (**Watch → Custom → Releases**), or follow the [releases feed](https://github.com/DamienReichhart/Homeport/releases.atom).

## Uninstalling

<Tabs syncKey="os">
<TabItem label="Windows">
Open **Settings → Apps → Installed apps**, find **Homeport**, and choose **Uninstall**.
</TabItem>
<TabItem label="macOS">Quit Homeport and drag it from Applications to the Bin.</TabItem>
<TabItem label="Linux">

```sh
sudo apt purge homeport       # Debian, Ubuntu
sudo dnf remove homeport      # Fedora, RHEL
sudo zypper remove homeport   # openSUSE
```

This also removes the Homeport repository. On Debian and Ubuntu, `apt remove` keeps it, along with the rest of the package's configuration, and `apt purge` removes it with its key. On Fedora and openSUSE the key stays in rpm's keyring; `rpm -q gpg-pubkey --qf '%{NAME}-%{VERSION}-%{RELEASE} %{SUMMARY}\n'` lists the keys, and `sudo rpm -e gpg-pubkey-<version>-<release>` removes Homeport's.

For the AppImage, delete the file. Its menu entry disappears with it.

</TabItem>
</Tabs>

Uninstalling leaves your data in place, so reinstalling brings everything back.

### The login entry

If **Start at login** is on, turn it off in **Settings → Desktop** before uninstalling: uninstalling leaves the login entry behind, pointing at a Homeport that's gone. To remove it afterwards:

| System  | Login entry                                                                                                                                                   |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Windows | **Task Manager → Startup apps**: disable **Homeport**, or delete the `Homeport` value under `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` |
| macOS   | Delete `~/Library/LaunchAgents/Homeport.plist`                                                                                                                |
| Linux   | Delete `~/.config/autostart/Homeport.desktop`                                                                                                                 |

## Removing your data

<Aside type="caution">
  This deletes your Hosts, their stored keys and certificates, your Managed Stack definitions, your
  Linked Stacks and their deploy history. Linked Stacks' folders stay where they are. Nothing on
  your Hosts is touched.
</Aside>

1. Delete Homeport's data and log folders:

   | System  | Folders                                                                               |
   | ------- | ------------------------------------------------------------------------------------- |
   | Linux   | `~/.local/share/com.homeport.app/`, `~/.config/com.homeport.app/`                     |
   | macOS   | `~/Library/Application Support/com.homeport.app/`, `~/Library/Logs/com.homeport.app/` |
   | Windows | `%APPDATA%\com.homeport.app\`, `%LOCALAPPDATA%\com.homeport.app\`                     |

2. Delete the encryption key from your keychain — the entry for `com.homeport.app`:
   - **macOS** — in **Keychain Access**, search for `com.homeport.app` and delete it.
   - **Windows** — in **Credential Manager → Windows Credentials**, remove the entry containing `com.homeport.app`.
   - **Linux** — in **Passwords and Keys** (Seahorse) or KWallet, delete the entry for `com.homeport.app`.

3. On your servers, remove Homeport's public keys from `~/.ssh/authorized_keys` — their comments start with `homeport@`.
