**Homeport** is a desktop app for managing Docker Engines anywhere — this machine's, or remote ones over SSH, TLS or TCP. It runs on Windows, macOS and Linux, is free, and is open source under the [GNU Affero General Public License, version 3](https://github.com/DamienReichhart/Homeport/blob/main/LICENSE).

Homeport doesn't run containers itself. It connects to the Docker Engines you already have, called **Hosts**, and gives you one window for everything on them: containers, images, volumes, networks and Compose **Stacks**.

## Words we use

Homeport names things precisely, and the docs follow it:

- A **Host** is a Docker Engine Homeport connects to. Every container, image, volume, network and Stack belongs to exactly one Host.
- A **Stack** is a Compose project running on a Host. A **Managed Stack** is one whose compose file Homeport keeps; a **Linked Stack** keeps its compose files in a folder on this computer; an **External Stack** was deployed some other way. You can **adopt** an External Stack to manage it.

The [glossary](/docs/reference/glossary/) has the full list.
