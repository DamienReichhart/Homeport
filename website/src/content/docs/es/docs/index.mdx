**Homeport** es una app de escritorio para gestionar Docker Engines, containerd e Incus estén donde estén —los de este equipo o remotos por SSH, TLS o TCP—, los Swarms que forman, los clústeres de Kubernetes a los que llega tu kubeconfig y los clústeres de Nomad que indiques, en la línea de Docker Desktop. Funciona en Windows, macOS y Linux, es gratuita y es de código abierto bajo la [GNU Affero General Public License, versión 3](https://github.com/DamienReichhart/Homeport/blob/main/LICENSE).

Homeport no ejecuta contenedores por sí mismo. Se conecta a los Engines que ya tienes, llamados **hosts**, y te da una sola ventana para todo lo que hay en ellos: contenedores, imágenes, volúmenes, redes y **stacks** de Compose. También se conecta a **clústeres** de Kubernetes y de Nomad, para ver lo que se ejecuta en ellos y gestionarlo. No se instala nada en ningún host ni clúster.

  <Card title="Gestionar Swarms" icon="seti:docker">

  <Card title="Ejecutar instancias de Incus" icon="laptop">

## Las palabras que usamos

Homeport nombra las cosas con precisión, y la documentación lo sigue:

- Un **host** es un Engine al que se conecta Homeport: un Docker Engine o uno compatible como Podman, containerd o Incus. Cada contenedor, imagen, volumen, red y stack pertenece exactamente a un host.
- Un **clúster** es un clúster de Kubernetes, añadido desde un contexto de tu kubeconfig, o un clúster de Nomad, añadido por la dirección de uno de sus agentes.
- Un **Swarm** es un Docker Swarm, que se encuentra a través de los hosts que forman parte de él y que nunca se añade por sí solo.
- Un **stack** es un proyecto de Compose que se ejecuta en un host, o un stack de Swarm que se ejecuta en un Swarm. Un **stack gestionado** es aquel cuyo archivo compose guarda Homeport; un **stack vinculado** guarda sus archivos compose en una carpeta de este equipo; un **stack sincronizado** sigue un repositorio git; un **stack externo** se desplegó de otra forma. Puedes **adoptar** un stack externo para gestionarlo.

El [glosario](/docs/reference/glossary/) tiene la lista completa.
