# Homeport terms — Japanese (ja)

Style: です/ます for sentences; buttons and menus as short nouns / verb stems (削除, 再デプロイ). Full-width 。、「」（） in Japanese text; half-width around code, commands and arguments. Loanwords without the long vowel, as Docker's Japanese docs write them (コンテナ, not コンテナー).
