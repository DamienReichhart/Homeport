# Italian (`it`) terms for Homeport

Conventions:

- Buttons and menu items: imperative, second person singular, as Windows and macOS do in Italian ("Rimuovi", "Salva", "Annulla", "Apri…"), never the infinitive ("Rimuovere").
- The user is addressed with "tu", as Windows 10/11 and macOS do ("Vuoi rimuovere…?", "Controlla…").
- Toast and status titles: noun + past participle agreeing in gender/number ("Immagine rimossa", "Container avviati").
- Elisions and apostrophes always typographic ’ (l’host, dell’immagine, un’istanza). Never ASCII '.
- Common nouns in lower case as English does in sentences (host, stack, cluster); Kubernetes kinds keep their capitals.
- Quotes inside text: «…».
- Plurals: `one` and `other`.
