## Notes added while translating

- Engine events (Docker Host "Events" page) → „Ereignisse“; Kubernetes Event objects → „Events“ (kind name kept).
- Nomad objects keep their English names but take German noun capitalisation: Job, Allocation, Task Group, Client-Node, Node-Pool, Deployment.
- drain (Swarm and Nomad) → „Leeren“ / „wird geleert“ / Verfügbarkeit „Geleert“.
- Remove → „Entfernen“; Delete (Kubernetes objects, Incus, volumes) → „Löschen“, keeping the English distinction.
- kill → „Beenden erzwingen“ / „zwangsweise beendet“; Take down (compose down) → „Herunterfahren“.
- Clean up → „Aufräumen“; prune toasts → „… entfernt, … freigegeben“.
- Rollback / Roll back → „Zurücksetzen“; Upgrade stays „Upgrade“.
- Parameters that carry English words ({verb}, {action}, {kind} of a git ref) are quoted „…“ so the sentence stays grammatical.
